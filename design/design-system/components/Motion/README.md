动效规则：界面先回应，再移动；移动从当前位置出发，带着使用者给的速度，随时可以被打断。

**你提供**：要动的值和目标。非手势的过渡用 CSS 变量（`spring-settle`、`duration-*`）；跟手的交互用 `Bowerbird.spring({ damping, response, onUpdate })`，配 `tracker()`、`project()`、`rubberband()`。

| 场合 | 做法 | 取值 |
|---|---|---|
| 按下 | pointer-down 立即反馈，松手提交 | 缩放 0.97，`duration-press` |
| 悬停、颜色、淡入 | 短过渡 | `duration-fade` + `ease-out` |
| 滑块、指示条、折叠箭头 | 临界阻尼弹簧，不回弹 | `spring-settle` + `duration-snappy` |
| 面板、对话框、快速预览 | 临界阻尼弹簧 | `spring-settle` + `duration-settle` |
| 拖放松手、甩动之后的落位 | 欠阻尼，轻微回弹 | 阻尼 0.8，或 `spring-flick` + `duration-flick` |
| 缩略图到达 | 淡入 + 去模糊 + 上移 6px | `duration-arrive`，一批错开 45ms |
| 菜单、提示等材质浮层 | 模糊与缩放一起到达，原点在触发处 | `blur-arrive`，缩放自 0.94 |

- **回弹只留给带动量的手势。** 一个只是淡入的菜单不该弹；一张被甩出去的卡片才该弹。
- **跟手**：拖动的对象贴着指针，保留抓取点的偏移；不要在松手后才动。
- **可打断**：任何动画途中都能再次抓住或改道，新动画从屏幕上的当前值出发，不从目标值出发。
- **落点看动量**：松手后不落到离松手点最近的位置，而是落到离「按速度预测的终点」最近的位置。
- **来去同路**：从哪里出现就回哪里去。菜单、对话框、快速预览的 `transform-origin` 设在触发它的元素上。
- **边界有弹性**：拖过头时越拉越紧（`rubberband`），不要硬停。
- 只动 `transform` 与 `opacity`。原型里面板折叠用了网格列宽过渡，正式实现请换成位移。
- **减弱动态效果**：位移与弹簧退化为 `duration-fade` 的淡入淡出，回弹取消，走马光停止。**降低透明度**：材质变实心。**提高对比度**：控件加 `line-control` 描边。三者都已写在 `bundle.css` 末尾。
- 不做循环的装饰动画。唯一持续运动的东西是「处理中」单元边缘的那道光，它在表达一件正在发生的事。
