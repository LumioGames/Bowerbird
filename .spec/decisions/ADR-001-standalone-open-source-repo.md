# ADR-001：作为独立开源仓库建设，项目名定为 Bowerbird

状态：Accepted
日期：2026-11-25

## 背景

需要一个统一管理游戏资产的工具，供美术、策划和 Agent 使用。要决定它放在游戏仓库里，还是单独成仓；以及叫什么名字。资产目前基本从零开始积累。

## 决策

- 新建独立仓库，不放进任何游戏工程。
- 定位为开源的通用资产管理内核；团队自己的制作规范以后在内核之上定制，不写进内核。
- 项目名定为 Bowerbird（园丁鸟）：这种鸟收集彩色物件并分类摆放，与“收集、整理、展示美术资产”对应。
- 管理器本身是资产的真值，游戏工程从它取用资产。

## 替代方案与否决理由

- **放进游戏仓库**：它是网页应用加服务，技术栈与发布节奏和游戏工程不同；资产库要服务多个消费者，不应绑定某个游戏；大文件不适合进游戏仓库。
- **命名为 AssetStudio**：与一个知名的 Unity 资源提取开源工具重名，开源后搜索结果与包名会冲突。
- **命名为 Hamster（仓鼠）**：形象贴切，但同名项目较多。

## 兼容影响

- knowledge/features/overview.md 写明定位与非目标。
- 项目名在 GitHub 与 npm 上的可用性尚未核实，核实不通过时需要新增一条 ADR 改名。
