# ADR-034：搜索语法增加 created:today|week|month

状态：提议
日期：2026-11-25

## 背景

原型修订说明「待确认」第 3 项：查询模型有 `created` 条件，但文本语法没有对应写法，筛选面板也就没有放创建时间。

本条是第一期实现时按「先找最接近的已有决定，找不到就选更少人工步骤、更不容易丢数据的做法」（ADR-013）补的，待评审。

## 决策

- 增加 `created:today`、`created:week`、`created:month`，与 `when:`（修改时间）对称。
- 搜索补全里的含义写「创建时间」。

## 替代方案与否决理由

- **用 `when:` 同时表示两种时间**：会让「本周新增」与「本周改过」混在一起。

- knowledge/features/search.md 文本语法表。
