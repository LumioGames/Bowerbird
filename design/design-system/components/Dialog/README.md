对话框打断当前任务，只用于必须先由人决定才能继续的事：破坏性操作的确认、需要补充信息的操作。

**你提供**：一句标题（就是那个问题本身）、一段说明（会发生什么、之后能不能撤回）、可选的受影响对象列表、按钮。

- 标题直接写成问题，带上对象的名字：「把 chest_basecolor.png 移入回收站？」，不写「确认删除」。
- 说明里永远回答两件事：**现在会发生什么**，**之后还能不能撤回**。
- 涉及其他资产时把它们逐个列出来（`bb-dialog__list` 里放 `bb-row--media`），不要只给一个数字。
- 按钮顺序固定：取消在左，确认在右；确认按钮写出动作本身。破坏性确认用 `bb-btn--danger`，其余用 `bb-btn--primary`。打开时焦点落在取消上。
- 能撤销的操作不弹对话框（采纳标签、设置阶段、移动），做完给一条可撤销的提示即可；确认框用多了，人会养成直接点过去的习惯。
- 背后用 `material-scrim` 压暗；面板从略小的尺寸用 `spring-settle` 放大进入，沿原路退出。Esc 与点遮罩等于取消。
