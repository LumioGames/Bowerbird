# ADR-033：添加资产库时，文件夹里已有文件就走首次打开的说明与进度

状态：提议
日期：2026-11-25

## 背景

原型修订说明「待确认」第 2 项：原型里「添加资产库…」只演示了空文件夹，首次打开的说明用评审控制重放。

本条是第一期实现时按「先找最接近的已有决定，找不到就选更少人工步骤、更不容易丢数据的做法」（ADR-013）补的，待评审。

## 决策

- 添加的文件夹是空的：直接成为空资产库。
- 已有文件但没有 `.bowerbird/library.json`：先显示首次打开的说明（会在每个文件旁写 `.bmeta`、哪些格式还没有插件能读），确认后登记并显示进度，可停止，下次接着登记。
- 已是资产库：直接打开。

## 替代方案与否决理由

- **添加时一律直接登记**：会在不知情的情况下往别人的文件夹里写满 `.bmeta`。

## 兼容影响

- knowledge/features/web-shell.md 资产库菜单与首次打开。
