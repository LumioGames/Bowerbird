提示条在内容旁边说明一个持续存在的情况，并把能做的事直接放在它下面。

**你提供**：级别、图标、一句标题、可选的一句说明、最多三个动作。

| 类 | 用在 |
|---|---|
| `bb-banner bb-banner--warning` | 警告级：上游已更新、处理失败、缺少插件。 |
| `bb-banner bb-banner--danger` | 错误级：断链引用、文件缺失、重复身份、元数据冲突。 |
| `bb-banner` | 说明与结果：复制完成后的说明、功能不可用的原因。 |
| `bb-banner--line` | 单行，用在页签顶部或空间紧的地方。 |

- 它出现在检查器的「问题」分区和详情页顶部，内容一致。
- 标题说**发生了什么**，说明说**具体是谁、什么时候、哪一个**，动作说**现在能做什么**。不写「错误」「警告」这两个词。
- 主要的那个动作用 `bb-btn--primary bb-btn--sm`，其余用默认小按钮。不可用的动作保留并置灰，原因写在下面的 `bb-hint` 里。
- 颜色只在底和图标上；正文始终是 `ink-1` 与 `ink-2`，级别永远有图标陪着。
- 问题解决后提示条原地变成一行结果，几秒后淡出，不要直接消失。
