检查器分区是右栏里的一块：一个可折叠的标题，下面是键值、标签、关系列表或插件自己的内容。

**你提供**：分区标题、可选的数量、内容。来自插件的分区再给一个插件标识，显示在标题行尾部。

- 结构固定：`bb-sec` > `bb-sec__head`（箭头、标题、数量、`bb-sec__by`）> `bb-sec__body`。点标题折叠，折叠状态按分区记在本机。
- 键值用 `dl.bb-kv`：键 76px 宽、`ink-3`；值 `ink-1`。能编辑的值直接是控件（下拉、输入框），不要另开编辑模式。
- 路径、GUID、内容指纹用 `bb-copy`：等宽、可截断、点击即复制并原地提示「已复制」。
- 人工描述是 `ink-1`；AI 描述低一级用 `ink-2`，前面带闪光图标，和 AI 标签是同一套语言。
- 分区之间只有一条 `line-hairline`，没有卡片底。分区顺序由外壳决定：预览、基本、描述、标签、阶段与校验、技术信息、关系、生产记录、版本、问题，最后是插件分区。
- **插件的边界**：外框、标题、折叠由外壳给；`bb-sec__body` 里面归插件。插件用同一套变量和 `bb-kv`，看起来就是一家，但标题行尾的标识让人知道这一块可以被替换。
- 数量为 0 的分区保持折叠并显示 0，不要隐藏——「没有问题」本身是信息。
