# ADR-025：需要渲染的缩略图懒加载，服务器不渲染；缩略图随资产库同步

状态：Accepted
日期：2026-11-25

## 背景

[ADR-008](ADR-008-thumbnails-by-viewer-cache-in-library.md) 定下模型等需要渲染的格式由打开着的页面在后台生成缩略图。审查时指出：没有页面开着时缩略图一直出不来，例如 Agent 夜里批量登记模型。审查报告建议增加一条命令，在服务器上启动不带界面的浏览器专门渲染。

讨论的结论是不增加这层复杂度：服务器上不一定有浏览器，纯命令行环境画不了 3D；服务器只负责存放与同步资产。

## 决策

- **服务器不渲染**。不做后台浏览器，也不做无人值守的渲染命令。
- **懒加载**。有人打开页面时，由他的浏览器渲染，先渲染屏幕上看得到的；渲染完交回服务器保存。没有人看的时候不渲染。
- **缩略图保存在资产库文件夹里，随资产库一起同步和做版本管理**。一个人渲染过，其他人同步下来就有，不必重新渲染。
- 不需要渲染的格式（图片、音频波形）仍在服务端生成，与 ADR-008 相同。

## 替代方案与否决理由

- **`bb render-worker`：在服务器上启动不带界面的浏览器**（审查报告待确认 7 的建议）：没人开页面也能出缩略图，但要求那台机器装有浏览器，Linux 服务器上常常没有；没有显卡时渲染很慢。
- **把它做成可选开关**：仍要维护这条路径；先不做。
- **在服务端用别的方式渲染 3D**：与查看器不是同一套代码，缩略图与预览会不一致（ADR-008 已否决）。
