# ADR-040：第一期不做「活动」面板，别人的改动用提示条与胶囊提示

状态：提议
日期：2026-11-25

## 背景

原型修订说明「待确认」第 9 项（F-03 建议）：别人或 Agent 的改动，原型只做了网格顶部「有 N 个新资产 · 显示」和详情页「被别人替换」横幅。

本条是第一期实现时按「先找最接近的已有决定，找不到就选更少人工步骤、更不容易丢数据的做法」（ADR-013）补的，待评审。

## 决策

- 第一期不做单独的活动面板。
- 新资产用网格顶部的胶囊提示；正在看的资产被替换用横幅；长任务完成与扫描结果用提示条。

## 替代方案与否决理由

- **做一个活动面板**：需要改动历史，内核不记（ADR-024）。

## 兼容影响

- knowledge/features/web-shell.md 状态呈现。
