标签是资产上的自由文字；人工标签是实心的，AI 标签是一条还没被人确认的建议。

**你提供**：标签文字；`Bowerbird.html.tag(text, { color, removable, ai })` 生成标记。`color` 来自标签定义（`tags.json`），只画成 6px 的圆点。

| 样式 | 含义 |
|---|---|
| `bb-tag` | 人工标签。`fill-rest` 实心底、`ink-1` 文字。可编辑处悬停出现移除按钮。 |
| `bb-tag bb-tag--ai` | AI 标签。虚线框、无填充、`ink-2` 文字，前面一个闪光图标，后面常驻「采纳」和「移除」两个按钮。 |

- 实心与虚线是唯一的区分方式，不要再给 AI 标签另配颜色。
- 采纳后原地变成人工标签，位置不跳；移除后不再出现。两个操作都可撤销（⌘Z），所以不弹确认框。
- 标签定义里的颜色只出现在圆点上，不铺满整个标签——整块的颜色留给物料阶段和问题。
- 网格单元上不显示标签；列表布局和检查器里显示。
