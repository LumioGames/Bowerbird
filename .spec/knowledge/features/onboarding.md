# 新手引导

第一次用 Bowerbird 的人，不用读说明就知道每一处是做什么的：浏览页上走一遍五步导览；其他页面第一次打开时，一个小手指指着这页最主要的按钮说一句话；资产库里第一次出现某类文件时，指着它说这种文件能做什么。代码在 `packages/web/src/onboarding/`，文字在外壳词典与各格式插件里，文案以 `design/docs/copy.md`「新手引导」为准。

## 背景 / 目标

- 欢迎页（ADR-063）解决了第一次导入；导入之后，使用者面对三栏、十来个页面和一堆按钮，不知道从哪里看起。
- 每次只讲眼前这一处，一两句话，指着真实的按钮讲；不放大段说明。
- 想跳过随时能跳过，以后还能再看。
- 内核不认识格式：新类型文件能做什么，由格式插件自己说。

## 设计

### 提示的样子

三种提示用同一个样子：

- **气泡**：一个小标题加一句话，下面是按钮。最宽 280 像素，放在被指的东西旁边：每条提示有自己先选的一侧（例如左栏里的东西放右边、页面底部的按钮放上面），那一侧放不下就换到对面，再不行换另外两侧，都放不下时放在空间最大的一侧，始终留在窗口里。
- **小手指**：气泡和被指的东西之间一个手指图标，指尖朝着被指的东西的边，轻轻地一点一点；它代替气泡的尖角。被指的东西外面一圈淡淡的强调色描边。系统设了「减少动态效果」时，手指不动。
- 屏幕上始终只有一个气泡。
- 气泡不挡操作：页面照常可以点、可以滚，被指的东西移动时气泡跟着走。它不是对话框，不抢键盘焦点；只有在用键盘按了导览上的「下一步」之后，焦点才移到下一个气泡的主按钮上。读屏软件通过一个一直在的播报区读出气泡里的话。
- 提示条从被指的东西上经过时，提示不收起。
- 有对话框、菜单或快速预览打开时，气泡先收起，关掉之后再回来。
- 被指的东西不在屏幕上时（左栏折叠、检查器关着、滚到看不见的地方、回收站是空的），这条提示不出，等它出现再出。

### 浏览页导览

**什么时候开始**：在浏览页上、网格里有资产、首次打开时的读取已经做完的时候。刚新建的空资产库不出导览，只显示原来的「把文件拖进来」；等第一批资产出现在网格里再开始。

**五步**，每步指一个具体的东西：

| 步 | 指着 | 小标题 | 一句话 |
|----|------|--------|--------|
| 1 | 左栏「待审」那一行 | 左栏 | 按状态看：待审、有问题、回收站。下面是磁盘上的文件夹。 |
| 2 | 网格里第一个资产 | 网格 | 双击打开，空格快速预览，右键看全部操作。 |
| 3 | 顶栏搜索框 | 搜索与筛选 | 按名字、标签、提示词找；筛选按阶段、格式、校验。 |
| 4 | 检查器的「标签」分区 | 检查器 | 选中一个资产，在这里改标签、阶段，看关系。 |
| 5 | 左栏左下角「设置」 | 设置、标签、任务 | 设置、标签管理、后台任务在这里。点 ? 可以再看这些提示。 |

- 气泡上是「{n}/5」「跳过」「下一步」；最后一步是「完成」。
- 进到第 4 步时如果没有选中资产，先选中网格里的第一个，让检查器显示它。
- 某一步要指的东西离开屏幕超过 1.5 秒（第 4 步等检查器加载，4 秒）就跳过这一步，计数照常按五步写。
- `Esc` 也是跳过，排在浏览页原有的 `Esc` 之后：先关筛选面板，再清空选择，都没有可做的时候才跳过导览。
- 中途离开浏览页时导览停在这一步，回来接着走；刷新页面后从第一步重来，直到点了「跳过」或「完成」。

### 各页提示

每处只在第一次打开时出现，指着这页最主要的按钮：

| 页面 | 指着 | 小标题 | 一句话 |
|------|------|--------|--------|
| 详情 · 查看 | 「关系」页签 | 查看 | 这里看文件本身；关系、版本、校验在这些页签里。 |
| 详情 · 关系 | 关系图中间的当前资产 | 关系 | 上游在左、下游在右；点节点走过去，拖线建立关系。 |
| 详情 · 版本（没有版本插件） | 「选择版本插件…」 | 版本 | 装上版本插件，才能预览和恢复旧版本。 |
| 详情 · 版本（有版本插件） | 版本列表里第一个旧版本 | 版本 | 选一个旧版本，和现在的对比或恢复。 |
| 详情 · 校验 | 「通过」 | 校验 | 通过还是打回由人决定，自动检查只供参考。 |
| 对比 | 「并排 / 卷帘 / 叠加 / 差异」 | 对比 | 换对比方式；卷帘的分界线可以拖。 |
| 校验队列 | 「通过」 | 校验队列 | 通过后自动下一个；打回要写意见。 |
| 完整性 | 第一条问题右边的第一个处理按钮 | 完整性 | 每条问题右边就是处理办法。 |
| 回收站 | 第一行的「恢复」 | 回收站 | 删掉的资产在这里留 {n} 天，可以恢复。 |
| 标签 | 第一个标签右边的「…」 | 标签 | 改名、合并在这里；拖动标签可以放进分组。 |
| 设置 | 左侧导航的「本机」 | 设置 | 你的名字、语言、主题在这里；其余随资产库走。 |

- 按钮只有「知道了」。点「知道了」或者直接按被指的那个按钮（鼠标按下或键盘按下都算，按下就打开菜单的按钮也一样），都算看过，以后不再出现。
- 版本页签两种情况算同一处：看过其中一种，另一种也不再出。
- 回收站的天数是这个资产库设置的保留天数。
- 导览正在浏览页上进行时，不出各页提示；各页提示只在各自的页面上出现。

### 新文件提示

**一类**按格式插件声明的格式算，例如 GLB、glTF、FBX 都是「3D 模型」一类。

- 网格里第一次看得到某一类文件、而这个浏览器还没为这类文件提示过时，指着网格里那个文件。
- 小标题是格式名（插件清单里的名字，按界面语言），一句话由格式插件给。
- 按钮是「知道了」与「打开看看」；「打开看看」打开这个资产的详情。
- 自己打开过某类文件的详情，这类也算看过。
- 插件没给这句话的格式不出提示；没有插件认领的文件（未知格式、缺少插件）也不出。
- 一条关掉之后，下一条等使用者换了地方再出：换了文件夹、视图、智能文件夹或查询，或从别的页面回到浏览页。导览结束（跳过或完成）后也一样，先等换一次地方。

内置插件给的话：

| 格式 | 一句话 |
|------|--------|
| 图片 | 能看单个通道、取色，平铺检查接缝。 |
| 视频 | 能逐帧看、设入出点，把一帧设为缩略图。 |
| 音频 | 按空格试听；能看波形和频谱，选一段循环。 |
| 3D 模型 | 能看通道、分屏，还能和四视图对照。 |
| 文档 | Markdown、网页原型、JSON 都能直接看。 |

### 先后

同一时刻只出一个，按这个顺序挑：浏览页导览 → 当前页面的提示 → 新文件提示。

### 左下角「?」

- 左栏底部右边那一组的最前面（「标签」「任务」之前）加一个只有图标的「帮助」按钮（问号），名字在悬停提示与读屏名称里。
- 点开是一个菜单：
  - 「重新看导览」：忘掉看过的一切（导览、各页提示、新文件提示），回到当前资产库的浏览页，从第一步开始。
  - 「关掉提示」：以后什么提示都不出，正在显示的立即收起；关掉之后这一项变成「打开提示」。打开后接着出还没看过的提示，已经看过的不再出。

### 记在哪里

- 看过什么、提示开没开，记在这个浏览器里（`localStorage` 的 `bowerbird.onboarding`），不分资产库：换一个资产库不会重来，换一台电脑或另一个浏览器会重来。
- 不记在服务端，也不写进资产库。
- 同一个浏览器开着几个页面时，一个页面里关掉提示，其他页面跟着变，不会被别的页面写回去。
- 导览结束、所有提示都看过之后，外壳不再查看页面，没有额外开销；「重新看导览」后再开始。

### 插件接口

格式插件的网页部分在 `FormatView` 上可以给一个可选的 `intro(locale)`，返回这一类文件的那句话；不给、返回 null 或出错时，这一类不出提示。文字用 `defineMessages` 写，必须有中文，其余语言按 ADR-061 回退。外壳不认识格式，只按格式标识找插件、问它要这句话。

### 测试

- 单元测试：记录的读写与容错；挑下一条提示的规则（先后、开关、看过、等换地方）；气泡的位置计算；词典齐全（`i18n.test.ts`）。
- 浏览器测试（中文）：导览从第一步走到完成、跳过、`Esc`；空资产库不出导览，上传第一个文件后出；各页提示的出现、「知道了」、点被指的按钮也算看过；新文件提示与「打开看看」；「?」菜单的重新看与关掉。
- 其他浏览器测试默认关掉提示（`e2e/helpers/test.ts` 在页面打开前写入「关掉」），只有新手引导的测试打开它。
