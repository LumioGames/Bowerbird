# 组件清单

「设计系统」列表示已经在 `design-system/components/` 里有 `preview.html` 和 `README.md`；「仅原型」表示只在原型里写了样式（`prototype/app.css`），还没整理进设计系统，程序实现时应先补进设计系统。正式版按 ADR-021 用 shadcn/ui 的基础组件、Magic UI 的动效与 Tailwind 实现，设计系统的变量照用；下表的变体是要对上的外观与行为。

## 基础

| 组件 | 变体 | 出处 |
|------|------|------|
| Button | 默认、主要（primary）、危险（danger）、幽灵（ghost）；尺寸 sm / 默认 / lg；纯图标；按下态（aria-pressed） | 设计系统 |
| Icon | Lucide 0.460 子集，12 / 16 / 24 | 设计系统 |
| SegmentedControl | 文字、图标、图标 + 文字；带不可用项并说明原因（对比方式） | 设计系统（不可用项：仅原型） |
| Select | 下拉按钮 | 设计系统 |
| Slider | 普通；两端带标签（叠加透明度） | 设计系统 |
| TextField | 单行、多行、带图标、带快捷键提示、出错态（data-invalid） | 设计系统 |
| Switch | 开 / 关 | 仅原型 |
| Tag | 普通、AI（未采纳）、添加；带采纳 / 去掉按钮；带计数 | 设计系统（按钮与计数：仅原型） |
| Kbd | 快捷键提示 | 设计系统 |
| Tabs | 带计数 | 设计系统 |

## 状态与反馈

| 组件 | 变体 | 出处 |
|------|------|------|
| StateMarks | 阶段（空心 / 半实心 / 实心）、校验、问题（带数量）、信息角标（宽 × 高、时长、面数、版本） | 设计系统 |
| Banner | 信息、警告、危险；行内（line）与块状 | 设计系统 |
| EmptyState | 图标 + 标题 + 说明 + 操作 | 设计系统 |
| Toast | 右下角弹出、最多叠 4 条、悬停不消失；普通、可撤销（停留更久）、自定义按钮文字（「查看」「挑选…」「切回」）；有上传面板时叠在它上面，详情与对比页时避开查看器底部控制区（ADR-021、E-28） | 仅原型 |
| Progress | 线性、环形（后台处理） | 设计系统（环形：仅原型） |
| Tooltip | 对比方式不可用原因（点不可用的方式时同一句话用提示条说出来） | 仅原型 |

| 组件 | 变体 | 出处 |
|------|------|------|
| Shell | 三栏，可拖宽、可收起；左栏底部设置条 | 设计系统（底部设置条：仅原型） |
| ListRow | 文件夹行（显示名、图标、计数、展开）、资产行、带操作 | 设计系统 |
| AssetCell | 网格、瀑布流；全部资产状态 | 设计系统 |
| InspectorSection | 可折叠、带来源插件标识 | 设计系统 |
| ContextMenu | 分组标题、勾选、快捷键、二级菜单（行本身也可执行） | 设计系统 |
| Dialog | 标题 + 说明 + 列表 / 表单 + 按钮（取消在左，主要在右，危险操作用危险色）；确认类是 alertdialog，点外面等于取消；表单与选择器是 dialog，点外面不关（E-07）；左下角可放次要内容（「添加资产库…」「Forge 提供」） | 设计系统 |
| Popover | 后台处理（处理中的资产 + 创建任务，可取消、挑选）、筛选面板（选项带数量）、插件顶栏按钮的面板 | 仅原型 |

| 新资产提示 | 网格顶部的胶囊「有 N 个新资产 · 显示」 | 仅原型 |
| QuickLook | 从缩略图展开、回到缩略图；方向键走当前列表或关系图 | 仅原型 |
| 页面框架 | 页面顶栏（返回、标题、副标题、右侧操作）+ 内容；覆盖浏览区 | 仅原型 |
| 设置卡片 | 行（名称、控件、说明、存放位置「随资产库 / 只在本机」）、导航、可复制的代码块（MCP 配置、命令行） | 仅原型 |
| 上传面板 | 右下角；每行名称、进度、取消；失败原因 + 重试；全部取消 | 仅原型 |

## 领域组件（全部仅原型）

| 组件 | 变体 |
|------|------|
| 浏览路径 | 普通、折叠（「…」菜单）；中间层级先缩短，当前层级完整 |
| 关系图节点 | 资产、生产记录、分组（叠放）、展开框；中心、选中、高亮、放入目标（历史版本只在有版本插件时） |
| 关系图连线 | 来源、引用、归属、上游已更新、指向的文件找不到；带标记 |
| 关系面板 | 类型、对方、位置名（「基础色 · chest_basecolor.png」）、备注；更换对方…、删除这条关系；找不到文件时的横幅 |
| 版本时间轴 | 关系图顶部（只在有版本插件时）；版本页签列表行（当前、恢复来的、未保存内容）；标签与关系的变更行（只在有版本插件时） |
| 卷帘分界线 | 线、圆钮、A / B 标签；拖动、方向键、双击居中；所有格式共用 |
| 对比页顶栏 | 两侧选择器（缩略图、名称、问题 / 阶段 / 校验标记、版本）、交换、方式、格式选项 |
| 技术信息对照表 | 表头（版本、说明、执行者、时间）；差异高亮与变化量（同一资产新减旧，不同资产 B 相对 A，左上角写明） |
| 3D 浮层 | 通道标签、视图方块、灯光方向盘、动作时间轴、尺寸线与比例尺、视图预设条；「查看选项」面板 |
| 网格转台 | 鼠标停在模型单元约半秒后实时渲染转台，移开即停；全页共用一个 WebGL 上下文（ADR-022） |
| 懒渲染缩略图 | 占位 → 进入视口 →「正在生成缩略图」→ 本页渲染的静帧（ADR-025） |
| 四视图对齐 | 按格子取视图；原画范围（虚线）、模型范围（实线）、尺寸线（偏差标黄）、宽高比（偏差超过 5% 标出）与尺寸读数；视图切换条（正 / 侧 / 背 / 顶）；没有匹配度（ADR-019） |
| 文本差异 | 并排行、合并行、空位斜纹 |
| 音频对照 | 两轨波形、播放头、正在听的一侧 |
| 校验队列 | 自动检查结果（只有尺寸）、操作栏（含打回意见）、上游卡片 |
| 校验结论 | 状态 + 谁 · 何时；意见块（打回时红色）；检查器里同样显示（ADR-024、E-16） |
| 完整性问题行 | 缩略图、说明、位置与发现时间、操作按钮组（都是默认样式，E-06） |
| 插件卡片 | 状态点（已启用 / 已禁用 / 加载失败 / 需要但未安装）、能力标签、原因、缺少外部工具与连续失败的警告、插件设置 |
| 创建表单 | 由插件声明生成：输入（按角色，选资产）、参数（文本、单行、分段、数字）、放到哪个文件夹、「某插件提供」（ADR-016） |
| 候选挑选 | 网格，可多选，「没选中的不进资产库」 |
| 资产库列表 | 名称、根文件夹、当前标记；单选 |
| 首次打开说明 | 文件数、.bmeta 示例、缺插件的格式列表 |
| 导出对话框 | 去向、目录、引用的资产、将写出的文件列表（换过对方的注明来源） |
| 包式资产 | 网格里显示成一叠；检查器「包内文件」（入口标记） |
| 描述 | 人工描述（点按编辑）、AI 描述（次要样式，可采用） |
| 文档属性行 | front matter 字段（目标尺寸） |

## 已知问题

- 深色模式下 `ink-2` 文字落在 `fill-hover` 上（悬停的菜单项、工具栏按钮）对比度 4.1–4.3，略低于 4.5。悬停是短暂状态，暂未调整；如要达标，把悬停态文字提到 `ink-1`。
