# ADR-054：网页外壳实现细则——地址参数、瀑布流、问题计数、上传、撤销、检查器事件、浏览路径、对比方式、确认文案、批量处理、参数表单

状态：提议
日期：2026-11-26

## 背景

web-shell.md 与原型规定了页面、布局与交互，下面这些没有定到能照着实现的程度：
- 浏览条件怎么写进地址；
- 瀑布流怎么排；
- 左栏「有问题」数的是什么；
- 复制、替换内容怎么撤销；
- 不可用的对比方式长什么样；
- 完整性页哪些问题能一次处理全部。

原型 CSS 把不可用的对比方式调暗了，与功能文档「不置灰」矛盾。

本条把第一期实现时自行定下的做法合并成文（ADR-013），待评审。

## 决策

**浏览页的地址**

| 参数 | 含义 |
|------|------|
| `folder=<路径>`、`view=untagged\|pending`、`smart=<名字>` | 在哪里看，三者只取一个，依次优先 |
| `q` | 条件片与自由词，用文本语法写；相对时间保持相对 |
| `tags=any` | 多个标签取「任一」，只在有标签条件时写 |
| `human=1` | 只看人工标签 |
| `aux=1` | 显示附属文件 |
| `sort`、`order` | 排序，选过才写 |
| `edit=<智能文件夹名>` | 正在修改这个智能文件夹的条件，同时打开筛选面板 |
| `select=<GUID>` | 选中一次，之后从地址里去掉 |

- 布局、缩略图大小、栏宽、列表列存在浏览器本地（`bowerbird.prefs`），不进地址。

**瀑布流**
- 每一项放进当前最短的一列，一样短时取最左边那列。
- 宽高比限制在 1/3 到 3 之间。

**左栏「有问题」的计数**
- 数的是有任何级别问题的资产个数，同一资产只算一次；不挂在资产上的问题（落单的元数据文件、库级的缺少插件）不算。
- 与完整性页标题里的「{n} 个资产」是同一个口径。

**上传**
- 用 XHR 发送，以拿到上传进度；同时最多 3 个。

**撤销**
- 复制的撤销：把副本移入回收站（带 `force`），再彻底删除这一回收项。
- 替换内容：
  - 有版本插件时，撤销是把上一版恢复为新的一版；
  - 没有版本插件时，提示条不带「撤销」，也不进 ⌘Z 的撤销栈。
- 「对比上游的变化」在没有版本插件时置灰，提示「需要版本插件」。

**检查器开关**
- 详情页的「检查器」按钮发窗口事件 `bb:inspector-toggle`。
- 外壳在开关变化时发 `bb:inspector-state`（`{ open }`），详情页据此更新按钮状态。

**详情页的浏览路径**
- 记在浏览器历史记录的 state 里：`{ trail: [{ id, tab, name }], from, fromLabel }`。
  - `trail` 最多 20 步；
  - `from` 是进入前的浏览页地址；
  - `fromLabel` 是第一级面包屑的文字。
- 换资产时推一条历史；换页签、上一个与下一个替换当前这一条。

**不可用的对比方式不置灰**
- 外观与可用的一样。悬停显示原因，点了用提示条说明原因，方向键跳过它。
- 以功能文档为准，原型 CSS 里的调暗是偏差。

**更换对方的确认框**
- 标题「更换 {位置} 的对方」。
- 正文「位置 {位置名} · 现在是 {当前对方} → {新对方}」，没有位置名时省掉前半句。
- 按钮「更换」。完成后提示条「{位置} 换成了 {新对方}」，带「撤销」。

**校验队列**
- 下面两种情况，提示「{名称} 已经有人审过了，跳到下一个」并跳过：
  - 轮到的资产已经不是待审；
  - 提交结论时返回冲突（ADR-038）。
- 快捷键照 copy.md：⌘↵ 通过，→ 跳过，打回的意见框里 ↵ 提交、Esc 取消，⌘Z 撤销上一个结论。

**完整性页的批量处理**
- 只给不需要逐条选择的问题类型：

  | 问题 | 批量操作 |
  |------|----------|
  | 断链 | 全部从回收站恢复 |
  | 重复身份 | 全部确认 |
  | 上游已更新 | 全部确认已复核 |
  | 处理失败 | 全部重试 |
  | 内容重复 | 全部标为副本 |

- 这一类里能做的超过一条时才出现，先确认「对 {n} 条「{类型}」执行“{操作}”？」。
- 文件缺失、元数据冲突、落单的元数据文件、缺少插件、缩略图过期，都要逐条选择，没有批量操作。

**创建方式的参数表单**
- 由创建方式的 JSON Schema 生成，支持两个扩展键：
  - `x-widget`：`textarea`（多行文字）或 `segmented`（分段按钮）；
  - `x-placeholder`：输入框的占位文字。
- 没写 `x-widget` 时：
  - 枚举不超过 4 个用分段按钮，多于 4 个用下拉；
  - 布尔用开关，数字用数字框；
  - 必填的文字框占位为「必填」。
- 输入资产按创建方式声明的 `inputs`（角色与格式），用外壳的选择器选，默认取当前选中的资产。

## 替代方案与否决理由

- **浏览条件拆成很多个地址参数**：智能文件夹与 Agent 都用文本语法，地址也用它，三处可以互相复制。
- **左栏只数错误与警告**：与完整性页的数字对不上，点进去人会以为少了。
- **不可用的对比方式置灰**：置灰的按钮点不动，人不知道为什么不能用。
- **完整性页对所有问题都给「全部…」**：文件缺失要逐个选重新定位的文件，元数据冲突要逐个选保留哪一份，一键处理会选错。
