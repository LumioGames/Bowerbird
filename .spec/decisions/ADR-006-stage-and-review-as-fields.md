# ADR-006：物料阶段与校验状态用独立字段，不用标签

状态：Accepted
日期：2026-11-25

## 背景

资产库里同时存在生产过程中的物料和游戏运行时实际使用的物料，人和 Agent 在查找时必须能分清。同时资产需要人工预览和校验，要能知道一个资产是否已被确认。需要决定用什么机制标记这两件事。

## 决策

- 物料阶段是资产的必填字段，三个固定取值：参考素材、生产物料、运行时物料。
- 校验状态是独立字段，四个取值：待审、通过、打回、免审；绑定到被校验时的内容指纹，内容变化后自动回到待审。
- 两者都可以由文件夹设置提供默认值。
- 源文件与导出的成品是两个资产，用来源关系连接，各有各的阶段。
- 搜索结果始终返回这两个字段。
- 规则检查的自动结论可以重算，只存索引；人工校验结论存元数据文件。

## 替代方案与否决理由

- **用标签标记阶段**：不需要新字段，但标签是自由文本，会漏打、写错、出现同义词，Agent 无法可靠过滤，也无法保证每个资产都有取值。
- **阶段取值由使用者自由定义**：更灵活，但内核与 Agent 无法对取值的含义做任何假设。固定三个取值，团队需要的更细分类用标签或自定义字段表达。
- **同一个资产内同时包含源文件与成品，按文件区分阶段**：减少资产数量，但阶段不再是资产级属性，筛选与关系都变复杂。
