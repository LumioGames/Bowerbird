右键菜单列出能对当前选中的资产做的事，从指针所在的点长出来。

**你提供**：菜单项（图标、文字、可选的快捷键）、分隔线与分组标题；插件添加的动作排在导出之后、删除之前。

- 顺序固定：打开、快速预览、对比 → 源文件（用默认程序打开 ⌘O、在文件夹中显示 ⌥⌘R）→ 物料阶段 → 整理（复制、移动、改名、建立关系、导出）→ 插件动作 → 移入回收站。破坏性的一项永远在最后，用 `bb-menu__item--danger`。
- 「物料阶段」是二级菜单：主菜单这一行右侧写当前值（多选不一致时写「混合」），悬停 60ms 向侧面展开；子菜单里三个阶段带色标和 1、2、3 键帽，当前值打勾。移向子菜单时短暂经过别的行不会立刻收起（180ms 宽限）。
- 「源文件」两项只在服务和浏览器在同一台机器上时可用；文件缺失的资产这两项置灰。
- 会打开对话框的项以省略号结尾（「对比…」「移动到…」）。
- 悬停用 `fill-hover`，不用强调色；菜单衬在 `material-popover` 上，上面只放 `ink-1`、`ink-2` 和 `danger-ink`。
- `transform-origin` 设在指针位置；靠近边缘时向内翻转，原点跟着翻。Esc、点空白处、选中一项都会关闭。
- 多选时菜单标题行写明数量（「3 个资产」），不适用的项置灰而不是消失。
