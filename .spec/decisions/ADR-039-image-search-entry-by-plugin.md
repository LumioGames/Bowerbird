# ADR-039：以图搜图的入口由语义搜索插件提供，内核不画

状态：提议
日期：2026-11-25

## 背景

原型修订说明「待确认」第 8 项（F-04）：没有语义检索插件时，以图搜图做不了。

本条是第一期实现时按「先找最接近的已有决定，找不到就选更少人工步骤、更不容易丢数据的做法」（ADR-013）补的，待评审。

## 决策

- 外壳不放以图搜图的按钮。
- 语义搜索插件通过界面扩展点（顶栏按钮、右键动作）提供入口，查询里用 `similarTo`。
- 没有语义插件时，带 `similarTo` 的查询返回「不支持」（search.md 已有规定）。

## 替代方案与否决理由

- **外壳画一个置灰的入口**：第一期永远不可用，只会让人困惑。

## 兼容影响

- knowledge/features/search.md 语义检索一节。
