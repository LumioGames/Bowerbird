# ADR-055：内置插件实现细则（图片、视频、音频、文档、关键词搜索）

状态：提议
日期：2026-11-26

## 背景

builtin-plugins.md 写了各内置插件支持的格式、提取的信息、缩略图和查看器，下面这些实现时才碰到：
- 动图的悬停动画放在哪；
- 概览图用哪张；
- 浏览器渲染失败了要不要重试；
- Markdown 里的图片算不算引用；
- 很短的音频怎么算响度；
- 只能并排时怎么跟人说。

本条把第一期实现时自行定下的做法合并成文（ADR-013），待评审。3D 模型插件的细则见 ADR-056。

## 决策

**图片**
- 缩略图：
  - `thumb` 为 512 像素 WebP（质量 82），`preview` 为 2048 像素 WebP（质量 86），都在服务端生成；
  - SVG 按密度栅格化；
  - 动图取第一帧。
- 动图（gif、webp、avif）另生成一份 256 像素的动态 WebP，放在 `scrub` 变体里，网格悬停时播放。
- 概览图（Agent 摘要用的图）不用 `scrub`，依次取 `turnaround`、`thumb`。
- 差异：两张图宽高比相差超过 5% 时，「差异」不可用，原因是「两张图的比例不一样，差异看不出东西」。
- 切图对比（ADR-036）：生产记录里没有区域参数时只能并排，原因是「这张切图没有记下它在原图上的区域，只能并排」。
- 四视图的尺寸线画在格子里的图形上。图形的范围是与背景色不同的像素的包围盒，背景色取四个角里占多数的颜色；找不到时向内缩 10%。

**视频**
- 封面取时长 1/10 处的一帧，不检测黑场。
- 关键帧条（6 帧，每帧 256 像素）作为摘要图，放在 `turnaround` 变体。
- 浏览器渲染失败时抛出带 `retryable` 的错误：
  - 浏览器解不了这种编码：`retryable: false`，不再重试，任务失败原因为「这台电脑的浏览器放不了这种视频（{编码}）」；
  - 超时与取消：可重试。
- 外壳的渲染工作者把没带 `retryable` 的失败当作可重试。
- 当前帧菜单：
  - 菜单项：「把当前帧设为缩略图」「把当前帧另存为图片资产」；
  - 提示条：「已把第 {帧} 帧设为缩略图」「已另存为 {名称}，来源指向这个视频」，后者带「查看」；
  - 另存的图片复制视频的标签、阶段与归属关系，加一条指向视频的来源关系。

**音频**
- 响度按 EBU R128：不足 400 毫秒（凑不满一个门限块）时，把全部采样当作一块计算。
- 绝对门限 −70 LUFS 仍然有效，静音得不出响度，这时不写 `loudness`。
- 对比只有并排（上下两条波形），选其他方式时提示「音频按上下两条波形对齐」。

**文档**
- Markdown 里的相对图片 `![](相对路径)` 当位置名报给内核，内核照常配对。
  - 跳过代码块与前言；
  - 去掉网址、`bb://`、`data:` 与绝对路径；
  - 去掉开头的 `./` 和 `?`、`#` 之后的部分，再做 URI 解码。
- 查看器按位置名取文件，取不到时退回字面路径。HTML 里的链接不当位置名。
- Markdown 不渲染里面的原始 HTML。
- 网页原型与其他格式对比时只能并排，原因是「网页原型只能并排」。

**关键词搜索**
- 全文索引、权重与短词回退见 ADR-053。

## 替代方案与否决理由

- **动图的悬停动画直接播放原文件**：原文件可能几十兆，网格里一屏几十个会拖慢页面。
- **概览图用动图的悬停动画**：Agent 拿到的是一张会动的小图，看不清内容。
- **解码失败也重试三次**：浏览器不支持的编码重试多少次都一样，只会占着渲染工作者。
- **Markdown 图片不当位置名**：文档里的配图换了名字或换了文件夹，就找不到了。

## 兼容影响

- knowledge/features/builtin-plugins.md：图片、视频、音频、文档各节。
- 3D 模型插件现在没有给渲染错误标 `retryable`，「没有 WebGL」与解不了的压缩也会重试三次。
