# ADR-022：3D 第一期 GLB、glTF、FBX 全做，OBJ 不支持；读不出的功能点击时提示

状态：Accepted
日期：2026-11-25

## 背景

原型的 3D 查看器是真实渲染，但模型是用代码拿基本体拼出来的，没有加载过任何真实的模型文件；基础色、粗糙度等通道是靠换材质模拟的。真实的 GLB、FBX、OBJ 打开后能做到什么程度没有验证过。需要定第一期对哪些格式做全。

## 决策

- **GLB、glTF、FBX 全做**。原型里有的功能都做：旋转查看、光照环境、贴图通道与单个分量、顶点色、线框、尺寸与比例尺、对比、出图、动画。
- **OBJ 第一期不支持**，按未知格式显示。
- **读不出来的功能不置灰**。某个文件里没有对应的信息时（例如一个 FBX 没有粗糙度），按钮照常显示，点击时用提示条说明「这个格式不支持」。
- **动手前先用真实文件验证**：拿几个真实的 GLB 与 FBX 跑一遍，确认哪些功能在 FBX 上经常读不出来。
- **顶点色只显示 R、G、B、A**，不显示各分量代表什么，程序不读规范文档。
- **网格里鼠标停在模型上时实时渲染转台**，不预先生成多帧缩略图。鼠标停住约半秒才开始加载，移开即停止；大文件要等几秒才动起来。

## 替代方案与否决理由

- **GLB 与 glTF 做全，FBX 与 OBJ 只做基础预览**（审查报告的原建议）：风险小，但 FBX 是常用格式，能做的应当都做。
- **入库时把 FBX 转成 GLB 再显示**：FBX 也能用上全部功能，但要额外安装转换工具，转出来的材质只是近似。以后需要时再加。
- **读不出来的功能置灰**：一眼能看出不可用，但看不出原因；改为点击时提示。
- **悬停时轮流显示 8 张预先渲染的图**：不用实时渲染，但每个模型要多生成 8 张图，成本更高。
