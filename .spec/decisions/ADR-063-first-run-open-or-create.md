# ADR-063：第一次使用：欢迎页给两条路——打开已有文件夹，或新建资产库

状态：Accepted
日期：2026-11-26

## 背景

- 仓库不再带样例资产库（测试时现场生成），下载下来是干净的。
- 第一次启动、还没有资产库时，原来只有一个「添加资产库…」按钮，要手动输入文件夹路径，没有「新建」。
- 使用者定下：空白的时候一定要引导第一次导入——要么把一个已有的文件夹作为资产库，要么新建一个文件夹作为资产库。

## 决策

**欢迎页**
- 没有登记任何资产库时显示。
- 一句话说明 Bowerbird 是做什么的，下面两个同样大的选择：
  -「打开文件夹」：把已有的文件夹作为资产库，里面的文件会被登记（每个文件旁边写一个 `.bmeta`，原文件不改动）；有文件时走首次打开的说明与进度（ADR-033）。
  -「新建资产库」：选一个位置、给个名字，新建一个空文件夹作为资产库；同名文件夹已存在且不是空的时候拒绝，并说明原因。
- 资产库菜单里的「添加资产库…」给同样两个选择。

**选文件夹**
- 不用手打路径：一个列出文件夹的对话框，从主目录开始，可以进出上一级，也可以粘贴路径；已经是资产库的文件夹标出来。
- 列文件夹的接口只接受本机请求（与「在文件夹中显示」同一规则，ADR-049）。从其他电脑打开页面时只能输入路径。
- 只列文件夹，不列文件、不读文件内容；隐藏文件夹不列；数量有上限（2,000）。
- macOS 上列主文件夹时，不看桌面、文稿、下载与媒体文件夹里面（也不看 /Volumes 下的卷），免得一打开对话框就弹系统的访问授权；进入这些文件夹是使用者自己的操作，那时才可能问。
- 「新建资产库」由服务端检查目标文件夹（`POST /libraries` 的 `create: true`），已存在且有内容时拒绝，检查与创建之间没有空档，Agent 也能用。
