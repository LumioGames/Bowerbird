页签在同一个对象的几个视角之间切换，对象本身不变。

**你提供**：页签名、可选的数量、当前项。容器 `role="tablist"`，每项 `role="tab"` 加 `aria-selected`；`Bowerbird.tabs(el, onChange)` 负责指示条定位与方向键。

- 用在详情页：查看、关系、版本、校验，之后是插件添加的页签。
- 插件页签排在内置页签之后，前面带拼图图标，文字颜色低一级，让人知道它来自插件。
- 数量气泡只在数字本身有用时出现（关系有几条、版本有几条）。
- 指示条是 `ink-1` 而不是强调色，用 `spring-settle` 滑到新位置；页签内容用淡入切换，不做左右滑动。
- 页签不超过六个；更多的收进末尾的「更多」。
