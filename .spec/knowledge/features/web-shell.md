# 网页外壳

网页外壳是 Bowerbird 的界面框架。它提供布局、导航、网格、检查器和各类流程，但不认识任何文件格式：具体资产怎么显示、怎么对比，由格式插件填进外壳留出的插槽。代码在 `packages/web`，界面长相以交互原型 `design/prototype/` 为准，文案以 `design/docs/copy.md` 为准。

## 背景 / 目标

- 浏览体验参考成熟的素材管理工具：左侧导航、中间网格、右侧检查器。
- 在此之上增加资产管理特有的内容：物料阶段、校验、关系与追溯、完整性问题。
- 十万级资产下保持流畅。
- 外壳的一切操作都通过公开接口完成。

## 设计

### 页面清单

每个页面都属于某一个资产库，地址以 `/libraries/<库>` 开头。`<库>` 是资产库的标识，与接口路径里的相同，见 [`api-and-agent.md`](api-and-agent.md)。

| 页面 | 路径 | 内容 |
|------|------|------|
| 浏览 | `/libraries/<库>` | 三栏主界面；查询条件保存在地址里，可以分享与回退 |
| 详情 | `/libraries/<库>/asset/<GUID>` | 单个资产的查看器与页签；`?tab=` 指定页签 |
| 对比 | `/libraries/<库>/compare` | 两个资产或同一资产的两个版本；`?a&b&av&bv&mode` |
| 校验队列 | `/libraries/<库>/review` | 逐个处理待审资产；`?folder` 或 `?format` 限定范围 |
| 完整性 | `/libraries/<库>/issues` | 全部完整性问题 |
| 回收站 | `/libraries/<库>/trash` | 已删除的资产 |
| 标签管理 | `/libraries/<库>/tags` | 标签的分组、颜色、改名、合并；入口在左栏 |
| 设置 | `/libraries/<库>/settings/<分区>` | 资产库、本机、Agent 接入、插件、任务五个分区，以及各插件自己的设置 |
| 插件页面 | `/libraries/<库>/plugins/<插件>/<页面>` | 插件登记的独立页面 |

- 打开不带库标识的根地址时，依次进入：这个浏览器上次选择的资产库、唯一登记的资产库、服务的默认库、第一个资产库。
- 一个资产库都没有时，显示欢迎页：一句话说明 Bowerbird 做什么，两个同样大的选择「打开文件夹」「新建资产库」（ADR-063）。
  - 两者都用选文件夹对话框：从主文件夹开始，可进出、可粘贴路径，标出已添加的与已是资产库的文件夹；从其他电脑打开页面时只有路径框。
  - 资产库菜单的「添加资产库…」给同样的两个选择。

### 浏览页布局

**左栏**：
- 默认宽 232 像素，可在 180 到 360 之间调；`⌘\` 折叠。
- 栏宽与开关记在这个浏览器里。

| 分区 | 内容 |
|------|------|
| 资产库菜单 | 左栏顶部显示当前资产库的名称，点开是资产库菜单 |
| 固定视图 | 全部、未打标签、待审、有问题、回收站，各带数量 |
| 智能文件夹 | 保存的查询，可新建、改名、编辑条件、用当前条件更新、删除 |
| 文件夹 | 资产库的真实目录树，带数量；可自定义显示名与图标。右键菜单有信息、新建子文件夹、改名、作为一个资产、扫描、移入回收站；把资产拖到文件夹上即移动 |
| 插件分区 | 插件添加的分区 |
| 页面入口 | 左栏底部四个只有图标的按钮，名字在悬停提示与读屏名称里：左下角「设置」，右边「帮助」（问号，点开是「重新看导览」「关掉提示」，见 [`onboarding.md`](onboarding.md)）、「标签」与「任务」。「任务」是一个小圆环，与顶栏后台处理按钮同一份数据：空闲时只有浅色底环；有资产在处理、创建或动作任务在跑、本页缩略图在等浏览器渲染时，一段弧在转；有失败且没有在处理的任务时整圈为淡淡的警告色。圆环细而小、颜色压低，不抢内容（使用者定下，2026-11-26）；悬停提示写「任务 · N 个正在处理」或「任务 · N 个失败」 |

- **「有问题」的数量**是有任何级别问题的资产个数，同一资产只算一次，与完整性页标题里的资产数一致（ADR-054）。数字变化时这一行闪一下；点它进入完整性页。
- 「作为一个资产」把文件夹变成包式资产，确认框里说明有几条关系会改指向包（ADR-041）。

资产库菜单有三项：

- 「资产库设置…」：打开设置页的资产库分区。
- 「在文件夹中显示」：在文件管理器里显示资产库的根文件夹；只在装 Bowerbird 的那台电脑上出现。
- 「切换资产库…」：
  - 列出这个 Bowerbird 登记的资产库，选中即切换；切换只影响当前浏览器，其他人正在看的页面不变，提示条带「切回」。
  - 也可以「添加资产库…」，输入文件夹路径与名称：
    - 文件夹是空的：直接成为资产库；
    - 已有文件但还不是资产库：先显示首次打开的说明（会在每个文件旁写 `.bmeta`、各格式有多少文件、哪些格式还没有插件），确认后登记，右下角显示进度，可以停止，下次接着做（ADR-033）；
    - 已是资产库：直接打开。

**顶栏**

- 前进、后退、当前位置的路径导航。
- 左栏与检查器的开关。
- 缩略图大小滑块（96 到 320）。
- 布局切换：瀑布流、等高网格（默认）、列表。
- 排序。
- 筛选按钮，展开筛选面板。
- 搜索框：接受关键词与文本语法，与筛选面板双向同步；空搜索框里按退格删掉最后一个条件片，Tab 或回车接受补全。
- 「开始校验」：只在待审视图里出现，进入校验队列。
- 上传与新建：没有安装创建插件时是「上传」按钮；安装了创建插件时变成「新建」菜单，「上传文件…」排第一，后面是各插件登记的创建方式。
- 扫描按钮。
- 后台处理：一个数字（正在处理的资产加进行中的创建任务），点开列出正在做的事，可以取消，创建任务需要后续操作时显示插件给的按钮（ADR-042）。渲染由打开着的页面按需完成，没有开关，见下面的缩略图懒加载。
- 插件添加的按钮。

**浏览页的地址**（ADR-054）：
- 在哪里看：`folder=<路径>`、`view=untagged|pending`、`smart=<名字>`，三者取一个。
- 条件：
  - `q` 用文本语法写条件片与自由词，相对时间保持相对；
  - `tags=any` 表示多个标签取任一，`human=1` 只看人工标签，`aux=1` 显示附属文件；
  - `sort` 与 `order` 在选过排序之后才写。
- 其他：
  - `edit=<智能文件夹名>` 表示正在修改它的条件，同时打开筛选面板；
  - `select=<GUID>` 选中一次后从地址里去掉。
- 布局、缩略图大小、栏宽、列表列存在这个浏览器里，不进地址。

**中间：资产网格**

- 虚拟滚动，只渲染可见范围内的单元；结果第一页 200 个，之后每次 500 个。
- 瀑布流把每一项放进当前最短的一列，宽高比限制在 1/3 到 3 之间，图片填满单元；等高网格显示整张图。
- 每个单元显示缩略图、名称，以及角标：
  - 左上：物料阶段的色标。
  - 右上：校验状态图标（待审、通过、打回）。
  - 左下：错误或警告级的问题标记（断链、上游已更新、缺失等）。
  - 右下：格式特有信息，如视频时长、模型面数、分辨率。分辨率写实际的宽×高，如 `1024×1024`、`512×1024`。
- 处理中、失败、等待渲染以占位图显示，不单独加角标。
- 缩略图懒加载：
  - 模型、视频这类需要渲染的缩略图不由服务器生成；
  - 单元进入视口前显示占位图；进入视口后，还没有缩略图的由当前浏览器在后台渲染，先渲染屏幕上看得到的，渲染完交回服务保存；
  - 缩略图保存在资产库里，一个人渲染过，其他人同步下来就有；没有人打开页面时不渲染。
- 悬停行为由格式插件定义：
  - 视频随鼠标横向移动显示对应画面（无声），下方有一条进度线；
  - 动图播放动画副本；
  - 鼠标停在模型上约半秒后开始转台：模型绕自身的竖直轴转，相机与灯光不动，只在已经有缩略图时才转，移开即停止（ADR-056）；
  - 音频悬停时不播放，按空格快速预览后才播放。
- 触屏上不做悬停效果，长按 0.5 秒打开快速预览（ADR-032）。
- 列表布局下显示为表格，列可选：名称、格式、阶段、校验、标签、大小、修改时间、技术信息；名称、格式、大小、修改时间可以点列头排序。

**右栏：检查器**

默认宽 320 像素，可在 280 到 480 之间调；`⌘I` 开关。对比、校验队列、完整性、回收站、标签、设置与插件页面上不显示检查器。

选中一个资产时，自上而下显示：

| 分区 | 内容 | 是否可编辑 |
|------|------|------------|
| 预览 | 缩略图，点击打开快速预览 | — |
| 问题 | 名称下方最多三条横幅，带与完整性页相同的处理按钮 | — |
| 基本 | 名称、路径、GUID（可复制）、大小、修改时间 | 双击名称可改 |
| 描述 | 人工描述；AI 描述以次要样式显示 | 是 |
| 标签 | 人工标签；AI 标签可采纳或移除 | 是 |
| 阶段与校验 | 物料阶段、有效校验状态、最近一次的校验结论（谁、什么时候、意见） | 是 |
| 技术信息 | 格式插件提供的尺寸、时长、面数等；四视图显示格子信息 | 否 |
| 包内文件 | 包式资产里的文件 | 否 |
| 关系 | 上游、下游、引用、被引用、归属，各自可展开 | 可建立与删除；更换对方在关系图里做 |
| 生产记录 | 方式、工具、提示词、执行者 | 仅追加备注 |
| 版本 | 版本记录列表，默认折叠 | — |
| 插件分区 | 格式插件与其他插件添加的分区 | — |

- 选中多个资产时，检查器切换为批量编辑：统一增删标签、设置阶段、设置校验状态、移动、删除。
- 未选中任何资产时，显示当前文件夹或视图的信息。
- 选中的资产已不在当前结果里时，显示「已不在这个视图里」。
- 别人或 Agent 新增了资产时，网格顶部出现「有 N 个新资产 · 显示」（ADR-040）。

文件夹形态下可以编辑显示名、图标、备注与默认值，并显示资产数量和最近修改时间（文件夹内资产最近一次修改的时间）。这些设置写入该文件夹的 `_folder.bmeta`，见 [`library-format.md`](library-format.md)。显示名只改变界面上的名称，不改磁盘上的目录名。

### 选择与操作

- 单击选中，按住修饰键多选或范围选择，拖动框选。
- 双击或按回车进入详情。
- 按空格快速预览：在浮层里显示查看器，方向键切换上一个和下一个，回车进入详情。
- 拖动到左栏文件夹即移动。
- 从桌面拖入文件或文件夹即上传到当前文件夹。
- 右键菜单：打开、快速预览、对比…、创建方式、用默认程序打开源文件与在文件夹中显示源文件（或下载源文件）、物料阶段、复制、移动到…、改名、替换为新版本…、建立关系…、导出…、移入回收站。
  - 物料阶段是二级菜单，当前取值显示在这一行上；悬停 60 毫秒展开，鼠标离开后有 180 毫秒的宽限再收起。
  - 一行可以同时带二级菜单和自己的动作：点击执行该动作，悬停展开二级菜单。
  - 「用默认程序打开源文件」与「在文件夹中显示源文件」是在装 Bowerbird 的那台电脑上执行的，只在那台电脑上打开页面时出现；从其他电脑打开页面时，这两项换成「下载源文件」。文件缺失时这几项置灰。
  - 选中的资产符合某个创建方式的输入时，菜单里列出这个创建方式，例如选中四视图时出现「生成模型」。

**键盘操作**

单键快捷键只有空格与 Delete（或退格）。其余功能用组合键或鼠标；方向键、回车、Esc 用于移动、打开、关闭。组合键在 Windows 上用 `Ctrl`，在 Mac 上用 `⌘`。

| 作用 | Windows | Mac |
|------|---------|-----|
| 移动选择 | 方向键 | 方向键 |
| 快速预览 | 空格 | 空格 |
| 进入详情 | 回车 | 回车 |
| 关闭快速预览、详情页、菜单与对话框；浏览页上先关筛选面板，再清空选择 | `Esc` | `Esc` |
| 删除（先弹确认，再移入回收站） | `Delete` 或退格 | `Delete` 或退格 |
| 全选当前结果 | `Ctrl+A` | `⌘A` |
| 聚焦搜索框 | `Ctrl+F` | `⌘F` |
| 复制 | `Ctrl+D` | `⌘D` |
| 撤销 | `Ctrl+Z` | `⌘Z` |
| 用默认程序打开源文件 | `Ctrl+O` | `⌘O` |
| 在文件夹中显示 | `Ctrl+Alt+R` | `⌥⌘R` |
| 折叠左栏 | `Ctrl+\` | `⌘\` |
| 开关检查器 | `Ctrl+I` | `⌘I` |
| 打开设置 | `Ctrl+,` | `⌘,` |
| 详情页里回到上一个资产 | `Ctrl+[` | `⌘[` |
| 详情页里上一个、下一个结果 | `←` / `→` | `←` / `→` |

设置物料阶段、打标签、切换对比模式没有快捷键，用鼠标操作。「用默认程序打开源文件」与「在文件夹中显示」的组合键只在装 Bowerbird 的那台电脑上有效。对比页与校验队列的按键见各自一节。

- 左栏的视图、智能文件夹、文件夹是三棵可以用键盘走的树：`↑` `↓` 移动，`→` `←` 展开与收起，回车打开，`Shift+F10` 打开右键菜单。网格单元格与列表行也可以用 `Shift+F10` 打开右键菜单（ADR-060）。
- 焦点在按钮、页签、开关、树节点等控件上时，空格与回车交给控件本身，不触发快速预览或进入详情。
- 快速预览打开后焦点移进面板并留在里面，查看器自己的按键照常可用。

### 详情页

**主体**是格式插件提供的查看器，占据主要区域。查看器的工具条由插件画在查看器里。

**侧边**是与浏览页相同的检查器，详情页右上的「检查器」按钮开关它（窗口事件见 ADR-054）。

**上一个、下一个**：从浏览页进入时，可以按浏览结果的顺序切换到上一个、下一个资产，显示「n / N」；版本页签上不响应方向键。

**浏览路径**：
- 在详情页里从一个资产走到另一个资产（例如在关系图上点节点）时，工具条显示走过的路径，例如「chest › chest.glb › chest.md」，超过两步时较早的折叠为「…」。
- 路径记在浏览器历史记录里，最多 20 步：换资产推一条历史，换页签与上一个、下一个替换当前这一条（ADR-054）。
- 返回按钮、返回组合键（Windows 上 `Ctrl+[`，Mac 上 `⌘[`）与浏览器后退都回到上一个资产，并停在离开时的页签。
- `Esc` 关闭详情页，回到进入前的浏览页。

**页签**

| 页签 | 内容 |
|------|------|
| 总览 | 只有设计对象有：归属于它的资产 |
| 查看 | 查看器；设计对象上叫「文档」 |
| 关系 | 关系图 |
| 版本 | 版本时间线 |
| 校验 | 最近一次的校验结论、自动检查的结果、通过与打回、「与上游对比」 |
| 插件页签 | 插件添加的页签 |

**关系图**

- 以当前资产为中心、从左到右的有向图：上游在左，下游在右。
  - 上游一直追溯到最顶层；
  - 下游默认展示两层，「+N 再展开一层」逐层展开；
  - 同一条生产记录的产出多于 4 个时叠成一摞，设计对象的成员多于 6 个时折叠，点开展开成一个框；
  - 可以缩放（35% 到 160%）与「适应」，带图例。
- 聚焦当前资产所在的这条链路，上游的其他下游不展开。
- 只显示当前的关系；按版本看过去的关系图暂不提供（见待解决）。
- 节点是资产缩略图卡片，带阶段色标与状态图标。产出它的生产记录也画成节点。悬停节点时高亮与它相连的边和节点；鼠标离开画布即清除高亮。
- 边按关系类型区分线型：来源为实线、引用为虚线、归属为点线。
- 由文件里的引用名自动配上的引用关系，在边被选中或相连的节点被悬停时显示位置名，例如模型文件里写的贴图文件名。
- 断链的边指向一个“缺失”占位节点；上游已更新的边带警告标记。
- 点击来源边显示生产记录：方式、工具、提示词、参数、执行者、时间。
- 点击节点，以该节点为中心重新展开，详情页随之切换到该资产，并计入浏览路径。
- 可以直接选中两个节点发起对比。
- 支持从图上建立关系：从一个节点拖线到另一个节点，选择关系类型。
- 可以更换关系：
  - 选中一条边，把它的对方换成另一个资产，选定新对方的方式与建立关系时相同；
  - 确认框标题「更换 {位置} 的对方」，正文「位置 {位置名} · 现在是 {当前对方} → {新对方}」；
  - 完成后出现「{位置} 换成了 {新对方}」与「撤销」；
  - 带位置名的关系更换后位置名不变，查看器按新的对方显示。
- 关系图是更换关系的唯一入口，检查器与查看器里都不提供。完整性页里断链引用的「重新指定…」跳到这里对应的那条边。
- 键盘：
  - 空格快速预览鼠标所指的节点，没有指向节点时预览中心资产；
  - 快速预览里 `←` / `→` 按从左到右的顺序在节点间移动；
  - 关闭快速预览后回到关系图；`Esc` 先关面板，再清空选择。

**版本时间线**

- 列出每条版本记录：版本号、时间、执行者、说明、大小。版本号按记录的先后从 v1 起编。
- 没有安装版本插件时，页签顶部用一句平实的话说明旧版本为什么不能预览，并提供「选择版本插件…」，可选 Lore 或 Git LFS。
- 安装了版本插件时，显示版本列表与选中版本的预览，提供「与当前版本对比」「恢复为当前版本…」。安装插件之前留下的记录没有保存内容，显示为「未保存内容」，不可预览。
- 只列内容的版本记录。标签、物料阶段、校验、关系的改动历史要由版本或历史插件提供，暂不显示（见待解决）。
- 恢复把旧内容写成一个新版本，例如「v3 恢复为 v1」，已有记录不变。
  - 确认框说明会成为第几个版本、校验状态回到待审、有多少个下游资产会被标为上游已更新。
  - 完成后可以撤销；撤销是再追加一条新的版本记录，不删除已有记录。

**校验页签**

- 通过还是打回只由人决定，自动检查不改变校验状态。页签里也有「通过」「打回…」。
- 只显示最近一次的校验结论：谁、什么时候、意见是什么。没有校验记录的列表。
- 自动检查的结果只显示，供人参考。内置的自动检查只有模型尺寸对照一条：模型的包围盒与设计对象的目标尺寸逐轴对照，显示数字与是否相符。其余检查由校验插件添加。
- 「与上游对比」：沿来源关系找到最近的上游图片或模型，打开对比页。

### 对比页

- 左右两侧各是一个资产，或某个资产的一个版本。每一侧都可以单独更换：换成另一个版本、换成相关的资产，或通过搜索选定。
- 两侧由同一个格式插件处理时（两侧格式相同，或插件声明能处理这一组合，例如模型插件处理模型对照图片），使用插件的对比视图；否则并排显示两个查看器。
- 对比模式：并排、卷帘、叠加、差异。
  - 哪些模式可用由格式插件按这一对资产声明；
  - 用不了的模式外观照常、不置灰，悬停显示原因，点击时用提示条说明原因，方向键跳过它（ADR-054）；
  - 两侧格式不同时，原因是「两侧格式不同，只能并排」。
- **卷帘分界线**是外壳的统一控件，所有格式的操作方式相同：
  - 拖动分界线或其上的把手移动；
  - `←` / `→` 在页面任何位置都能微调，按住 `Shift` 步长更大；
  - 双击回到正中；两侧各有 A、B 标签；
  - 在画面其他位置拖动仍是该格式自己的操作，例如平移、旋转；
  - 切换模式或更换某一侧时，分界线位置保持不变。
- 下方的信息表并列两侧的技术信息，不同的值高亮并给出差值，例如「+168 · +7%」。旧版本一侧只有文件大小。
- 对比同一资产的两个版本时，有版本插件就提供「把 v{n} 恢复为当前版本…」，确认后按恢复处理（见版本时间线）。
- 模型对照四视图时，按图片元数据文件里的格子信息（`views`）取出对应的视图，可以并排、卷帘、叠加。没有格子信息的图片只能与模型并排，点卷帘或叠加时用提示条说明原因。各格式支持的模式与对比方式见 [`builtin-plugins.md`](builtin-plugins.md)。
- `Esc` 或 `⌘[` 关闭对比页。

**发起对比的入口**

- 浏览页选中两个资产后的右键菜单。
- 关系图上选中两个节点。
- 版本页签的「与当前版本对比」。
- 校验页签与校验队列的「与上游对比」：沿来源关系找到最近的上游图片或模型。
- 「上游已更新」提示里的「对比上游的变化」，需要版本插件；没有时置灰并说明「需要版本插件」。

### 校验队列

用于连续处理待审资产：

- 一次显示一个资产：
  - 左边是查看器；
  - 右边是生产记录、AI 标签（可采纳或去掉）、最多 4 个上游资产与设计对象，点开是快速预览；
  - 「与上游对比」打开与最近的上游图片或模型的对比页；模型对照带格子信息的四视图时默认为卷帘。
- 操作：通过、打回（必须填写意见）、跳过。通过还是打回只由人决定。
- 快捷键（照 copy.md）：⌘↵（Windows 上 `Ctrl+Enter`）通过，`→` 跳过；打回的意见框里回车提交、`Esc` 取消；⌘Z 撤销上一个结论。
- 处理完自动进入下一个。
- 轮到的资产已经被别人审过，或提交时返回冲突，提示「{名称} 已经有人审过了，跳到下一个」并跳过（ADR-038）。
- 文件缺失、还在处理、看不了、缺少插件、带错误级问题的资产暂不进入，并说明原因。
- 一轮结束后给出小结，可以「再审跳过的 N 个」。
- 队列范围可以是全部、一个顶层文件夹或一种格式。
- 自动检查的结果显示在查看器下方，只供参考，不改变校验状态。内置只有模型尺寸对照一条，其余由校验插件添加。

### 流程与对话框

**上传**

入口是顶栏的「上传」按钮或「新建」菜单里的「上传文件…」，也可以直接拖入。

1. 拖入或选择文件，显示目标文件夹和将继承的默认值。
2. 可在上传前统一设置阶段、标签、来源资产，可以选择免审、保留文件夹结构。
3. 遇到同名文件逐个询问：替换为新版本、保留两者、跳过，可勾选“对其余同名文件同样处理”。
4. 上传过程在右下角显示每个文件的进度，可以取消单个或全部，失败的显示原因、可以重试；同时最多传 3 个，用 XHR 取得进度。
5. 完成后新资产立即出现在网格里，缩略图随后补上。

**新建**

安装了创建插件时，从顶栏的「新建」菜单或右键菜单选择一个创建方式：

1. 外壳按这个创建方式声明的参数表单与输入资产显示表单；从右键菜单进入时，选中的资产已填入对应的输入。带自己页面的创建方式改为打开插件登记的页面。
   - 表单由参数的 JSON Schema 生成：`x-widget` 可取 `textarea`（多行文字）或 `segmented`（分段按钮），`x-placeholder` 给占位文字；
   - 没写时，枚举不超过 4 个用分段按钮、多于 4 个用下拉，布尔用开关，数字用数字框（ADR-054）。
2. 发起后成为一个创建任务，与入库处理的任务列在同一处，显示进度，可以取消。
3. 插件请使用者做后续操作时（例如挑选候选），提示条、顶栏后台处理与设置页的任务分区都出现插件给的按钮，点了打开插件页面（ADR-042）。失败时提示条带「查看」，打开任务分区。
4. 登记的产出像上传的文件一样出现在网格里，带生产记录与来源关系。

**复制**

- 副本的名字是原名加下划线和数字，例如 `chest_1.png`、`chest_2.png`、`chest_3.png`。
- 复制完成后只出现一条提示条，可以撤销。原件没有被引用时是「已复制为 {副本名}」；原件被引用时是「已复制为 {副本名}，原来的引用仍指向原件」。
- 撤销复制是把副本移入回收站再彻底删除（ADR-054）。
- 复制后不提供把引用改指到副本的入口。要让某个引用方改用副本，在它的关系图里更换那条关系。

**替换为新版本**

- 确认框说明「文件名和编号不变，新内容成为 v{n}，校验回到待审。」
- 有版本插件时提示条带撤销，撤销是把上一版恢复为新的一版；没有版本插件时旧内容不保留，提示条不带撤销。
- 别人正在看的资产被替换时，详情页出现横幅「{谁} 刚把它替换成了 v{n}」，带「显示新版本」。

**删除**

- 删除任何资产都弹确认框，有没有被引用都一样。
- 资产被引用时，确认框里多一句提示：有多少个资产引用它，删除后这些引用会变成断链；下面列出这些引用方。
- 删除文件夹时，里面有资产被文件夹外引用，确认框同样列出引用方（ADR-047）。
- 确认后资产移入回收站。回收站默认保留 7 天，天数在设置页的资产库分区里改。

**建立关系**

选择关系类型，再通过搜索或拖放选定对方。建立来源关系时可以同时填写生产记录。

**上游已更新**

资产带有该标记时，检查器与详情页显示一条提示，提供三个操作：对比上游的变化（需要版本插件，没有时置灰）、确认已复核、替换本资产内容。

**导出**

- 列出将写出的文件与总大小，可以连同依赖、保持目录结构或拍平。
- 默认下载压缩包；在装 Bowerbird 的那台电脑上还可以直接导出到目录。

**撤销**

- 可以撤销的操作完成后，提示条上带「撤销」。
- 全局撤销键（Windows 上 `Ctrl+Z`，Mac 上 `⌘Z`）撤销最近一次可以撤销的操作，提示条消失后仍然有效，最多记 50 步。
- 撤销只管本次打开页面期间做的操作。

### 提示条与对话框

- 报错、提示、操作结果都用提示条：从右下角弹出，几秒后渐隐消失。
- 同时有多条时叠着排，不互相顶掉。
- 鼠标停在上面时不消失。
- 带「撤销」的提示条多留几秒。
- 需要人做决定的用居中的对话框，不用提示条。
- 查看器里某个功能在当前文件上读不出对应的信息时（例如一个 FBX 没有粗糙度），按钮照常显示，不置灰；点击时用提示条说明「这个格式不支持」。
- 别人或 Agent 的改动不另做活动面板：新资产用网格顶部的胶囊提示，正在看的资产被替换用横幅，长任务完成用提示条（ADR-040）。扫描开始时提示「正在扫描…」。
  - 正在扫描或网格是空的时候，新资产直接出现在网格里，不收进胶囊；自己复制、恢复、作为一个资产、撤销出来的资产也不算新资产（ADR-060）。
- 扫描结束（ADR-060）：
  - 自己发起的扫描：提示「扫描完成 · 新增 {n} 个 · 发现 {m} 条问题」，有问题时带「查看」；没有变化时提示「扫描完成，没有变化」。
  - 文件监听与定时扫描：只在有变化时提示。
  - 首次登记有自己的进度面板，不弹提示条。
  - 扫描发现文件不见了：「扫描发现 {名称} 不见了」，多个时「扫描发现 {n} 个文件不见了」。

### 状态呈现

| 状态 | 网格单元 | 详情页 |
|------|----------|--------|
| 加载中 | 骨架占位 | — |
| 处理中 | 占位图加进度指示 | 查看器可用，缺失的信息显示为加载中 |
| 等待渲染 | 占位图；进入视口后由当前浏览器渲染 | 查看器正常工作 |
| 处理失败 | 格式图标加失败标记 | 显示错误信息与重试按钮 |
| 未知格式 | 通用文件图标 | 显示文件信息与下载按钮 |
| 缺少插件 | 通用图标加提示 | 说明需要安装哪个插件 |
| 文件缺失 | 置灰的最后一次缩略图 | 显示问题与处理选项 |
| 查看器出错 | — | 错误信息与下载原文件 |

空状态与出错：

| 情况 | 显示 |
|------|------|
| 空资产库 | 「把文件拖进来」与「选择文件」 |
| 空文件夹 | 「这个文件夹是空的」与「上传」 |
| 没有结果 | 「没有符合条件的资产」与「去掉最后一个条件」「清空」 |
| 加载失败 | 「没有加载出来」与「重试」 |
| 连不上服务 | 「连接不到 Bowerbird 服务」，写出服务地址，带「重试」 |
| 资产库打不开 | 「这个资产库现在打不开」 |

### 完整性页

- 标题写「{n} 个资产 · {m} 条问题」，按类型分组列出全部问题，可以按级别筛选（错误、警告、提示，ADR-035）。
- 每条问题显示涉及的资产、具体的关系、发现时间。
- 每条问题右侧是该类型可执行的处理按钮；用不了时置灰并说明原因（例如对方不在回收站里，不能恢复）。
- 断链引用的「重新指定…」跳到引用方的关系图里对应的那条关系，在那里更换对方。
- 批量处理「全部…」只给不需要逐条选择的问题类型（ADR-054）：

  | 问题 | 批量操作 |
  |------|----------|
  | 断链 | 全部从回收站恢复 |
  | 重复身份 | 全部确认 |
  | 上游已更新 | 全部确认已复核 |
  | 处理失败 | 全部重试 |
  | 内容重复 | 全部标为副本 |

  这一类里能做的超过一条时才出现，先确认「对 {n} 条「{类型}」执行“{操作}”？」。文件缺失、元数据冲突、落单的元数据文件、缺少插件、缩略图过期都要逐条处理。

### 设置页

标签管理以外的管理功能合在一个设置页里，左侧导航分区：

| 分区 | 内容 |
|------|------|
| 资产库 | 随库走的设置：名称、默认物料阶段、需要的插件、回收站保留天数（默认 7 天）、缓存占用与清理 |
| 本机 | 你的名字、监听地址与端口、定时扫描间隔、后台并发数、界面语言、主题 |
| Agent 接入 | Agent 搜索范围，以及 MCP 与命令行的接入方法 |
| 插件 | 已安装插件及其状态，安装、更新、卸载、启用、停用 |
| 任务 | 创建任务（进度、取消、插件给的后续按钮）；管线各阶段的排队数量与处理速度，没有插件处理的阶段不显示；扫描进度与「停止」「立即扫描」；失败任务的原因，可以逐个或全部重试，重试也没用的不给重试，缺插件的给「去安装」 |
| 各插件的设置 | 每个启用的插件一项，内容来自插件的设置页插槽；只写的设置项只显示「已设置」 |

- 把监听地址改成对局域网开放时先提醒风险：局域网里任何人都能读写资产库，也能在这台电脑上安装插件、运行程序。
- 名字作为执行者留在之后的写操作上，存在这个浏览器里。没有填写时执行者记为 `user:unnamed`，界面上显示为「未署名」。首次打开时不询问名字。
- 插件的设置项按清单里声明的 `scope` 保存到资产库或本机，见 [`plugin-system.md`](plugin-system.md)。

### 插槽

外壳留给插件的位置：

| 插槽 | 位置 | 典型用途 |
|------|------|----------|
| 查看器 | 详情页主体、快速预览、校验队列、对比页 | 格式的显示，连同它自己的工具条 |
| 对比视图 | 对比页主体 | 格式特有的对比 |
| 网格单元 | 浏览页网格 | 悬停效果，例如视频拖动、模型转台 |
| 渲染函数 | 后台的渲染工作者 | 在浏览器里生成缩略图与摘要图 |
| 检查器分区 | 检查器内 | 格式特有的信息与控件 |
| 详情页签 | 详情页 | 格式特有的专用视图 |
| 顶栏按钮 | 浏览页顶栏，可带弹出面板 | 插件的入口，例如以图搜图（ADR-039） |
| 新建菜单项 | 顶栏「新建」菜单；选中的资产符合输入时也出现在右键菜单 | 创建插件登记的创建方式 |
| 左栏分区 | 左栏 | 模板插件的设计对象列表 |
| 独立页面 | `/libraries/<库>/plugins/<插件>/<页面>` | 插件自己的管理页面、带自己界面的创建方式、挑选候选 |
| 设置页 | 设置页左侧导航里各插件自己的一项 | 插件设置 |

- 文档的文字卡片由外壳按插件给的标题与摘录画，不用网格单元插槽。
- 插件动作的右键菜单项还没有做，动作现在通过接口执行。

### 前端状态

- 服务端数据通过查询缓存管理，以事件流驱动局部失效；有后台处理时，任务概况每 5 秒拉取一次。
- 当前资产库与当前查询保存在地址里；布局、缩略图大小、栏宽、名字、语言等界面状态保存在这个浏览器里。选中项不保存。
- 写操作采用乐观更新，失败时回滚并用提示条说明。

### 基础组件

- 外壳的基础件用 shadcn/ui：按钮、菜单、对话框、弹出面板、表单、表格等，键盘操作与焦点管理由它处理。
- 动效用 Magic UI，需要哪个效果取哪个。
- 样式用 Tailwind。详情、对比、校验队列、完整性、设置等页面另有一份手写的样式表，同样使用设计系统的变量。
- 设计系统定下的颜色、间距、圆角、动效时长等变量照用，套在这套组件上；界面长相以交互原型为准。设计系统里手写的组件样式只作长相的参照。
- 插件界面用同一套：`plugin-sdk` 把这些组件与主题变量提供给插件，见 [`plugin-system.md`](plugin-system.md)。

### 外观与多语言

- 提供深色与浅色主题，默认跟随系统。
- 界面文字外置，提供简体中文、English、日本語、한국어，在设置页的本机分区切换（ADR-061）。
  - 语言列在 `@bowerbird/schema` 的 `LOCALES` 一处；简体中文是源语言，缺的文字按当前语言 → 英文 → 中文回退。
  - 设置页本机分区的「界面语言」一行（带地球图标，非英文界面下另注一个英文词 Language，任何语言下都找得到）：第一项「跟随系统（{当前匹配到的语言}）」，后面是各语言，各用自己的文字写名字。
  - 默认是跟随系统：按浏览器的语言列表匹配（`ja-JP` → 日语、`zh-TW` → 简体中文），都不匹配用英文；浏览器语言一变，界面立即跟着变。选了某一种语言后就固定用它，选回「跟随系统」又跟着浏览器走。
  - 切换语言立即生效，不用刷新页面；选择只存在这台浏览器里。
  - 加一种语言只改数据：在 `LOCALES` 里加一行，再加一个词典文件夹 `packages/web/src/i18n/<语言>/`，外壳按文件夹自动找到它。
  - 服务端的报错只有中文：中文界面原样显示，其他语言按错误码显示一句通用的话。
  - 日语、韩语界面优先用各自的系统字体；韩语在词与词之间换行。
  - 日期按各语言的习惯写（「11 月 24 日 16:42」「Nov 24 16:42」「11月24日 16:42」「11월 24일 16:42」）。
  - 插件交给外壳的文字（插件名、格式名、设置项、创建方式与动作、任务消息、插槽标题）按插件清单的 `l10n` 显示；网格角标与自动检查的说明先问插件的网页部分（`formatBadge`、`validators`），没有时显示服务端写下的原文（ADR-062）。
- 颜色、间距、圆角以主题变量定义，插件界面使用同一套变量。
