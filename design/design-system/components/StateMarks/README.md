物料阶段、校验状态、问题这三组信息会同时落在一张缩略图上；每组有自己的角、自己的形状、自己的图形语言，去掉颜色也不会混。

**你提供**：资产的 `stage`、`review`、`issue`（可无）和格式插件给的一段信息文字。缩略图上用 `Bowerbird.html.markStage / markReview / markIssue / markInfo`；列表与检查器里用带文字的 `html.stage / review / issue`。

| 组 | 位置 | 形状 | 怎么读 | 颜色 |
|---|---|---|---|---|
| 物料阶段 | 左上 | 圆 | **填充多少**：空心 = 参考，半满 = 生产，实心 = 运行时 | `stage-reference` / `stage-production` / `stage-runtime` |
| 校验状态 | 右上 | 圆角方 | **线条图标**：时钟 = 待审，对勾 = 通过，折返箭头 = 打回 | `ink-1` / `accent-ink` / `danger-ink` |
| 问题 | 左下，贴边 | 旗标 | **唯一实心的角标**，图标说类型，底色说级别 | `danger-fill` 错误 / `warning-fill` 警告 |
| 格式信息 | 右下 | 文字 | 时长、面数、尺寸 | `ink-1` |

- 物料阶段**始终显示**，它是「这个东西能不能直接用」的首要依据。
- 免审不显示角标：没有需要人做的事，就不占位置。列表与检查器里仍写出「免审」。
- 一个资产有多个问题时，旗标显示最高级别的图标和数量。信息级的问题（内容重复、手动缩略图过时）不上缩略图，只在完整性页与检查器里出现。
- 处理中、等待渲染、处理失败、未知格式、文件缺失是**缩略图本身的状态**，画在缩略图中间，不是第五种角标。
- 角标 18px 高，衬在 `material-mark` 上，保证压在任何作品上图标都有 3:1。缩略图小于 96px 时只保留阶段和问题。
- 阶段色只给色标图形上色；旁边的文字一律 `ink-2`。
