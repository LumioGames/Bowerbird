# ADR-056：3D 模型插件实现细则——尺寸容差、附属文件、内嵌贴图、FBX、分屏与通道、缩略图、悬停转台、出图、对比控件、压缩扩展

状态：提议
日期：2026-11-26

## 背景

builtin-plugins.md 的 3D 模型一节写了要做什么，下面这些实现时才定：
- 尺寸「相符」的容差；
- `.bin` 什么时候认领；
- 打包在文件里的贴图能不能替换；
- FBX 的旧材质怎么显示；
- 分屏怎么画；
- 网格悬停转台怎么转。

转台原先做成相机与灯光绕模型转，使用者反馈「像相机在动」，已改为与原型 `model.js` 的转台一致。

本条把第一期实现时自行定下的做法合并成文（ADR-013），待评审。

## 决策

**尺寸对照**
- 「相符」的容差取 1 厘米与目标尺寸的 2% 中较大的一个。

**附属文件 `.bin`**
- 同一文件夹或上两层内，有 `.gltf`（不超过 64 MB）在 `buffers[].uri` 里引用它时才认领。
- 认领为附属文件：格式 `gltf-buffer`，优先级 10，没有缩略图。

**内嵌贴图的位置名**
- glTF/GLB：
  - 有名字的打包图片，以 `image.name` 为位置名，没有后缀时按 MIME 补上；
  - 没名字的打包图片与 `data:` 图片没有位置名；
  - 显示时，有关系填了这个位置就用关系指向的图片替换。
- FBX：只取文件名作位置名。内嵌的贴图不能替换。
- 插件在 `ProbeResult.embedded` 里列出打包在文件里的位置名，内核照常配对，没配上的不算「找不到」。

**FBX**
- Phong 与 Lambert 材质转为标准材质：
  - 金属度为 0；
  - 粗糙度：Phong 取 √(2 /（高光指数 + 2）)，Lambert 取 1。
- 这类材质的粗糙度、金属度通道算读不出，点了提示「这个格式不支持」。是否读得出在查看时判断，不存下来。
- 单位按 `unitScaleFactor / 100` 换算成米。

**分屏**
- 每路通道单独渲染一遍，共用一台相机。
- 材质按屏幕区域丢弃区域外的像素：卷帘按半平面，多条按斜条。斜条倾斜 22°，卷帘的角度可以拖动，大约 ±1.3 弧度。
- 多条时 2 到 4 条，默认 3 条：
  - 每条有自己的通道标签，标签里就是通道菜单；
  - 多于 2 条时可以去掉；
  - 「+」按完整、基础色、法线、粗糙度、金属度、遮蔽的顺序，加下一个读得出的通道。

**通道输出**
- 调试分支把一项材质输入直接写到像素，跳过光照与色调映射。
- 编码：
  - 基础色与自发光按 sRGB 编码；
  - 粗糙度、金属度、遮蔽（没有时为 1）、透明度（不透明材质为 1）、顶点色输出原值；
  - 法线用覆盖材质输出世界空间法线，映射到 0–1，含法线贴图与凹凸贴图。
- 选单个分量时显示为灰度；基础色选「全部」时保留透明度。

**顶点色菜单**
- 只有一组：直接给 R、G、B、A。
- 有多组：先选 `COLOR_n`，再选分量。
- 没有：菜单项显示「无」，查看器显示「无顶点色」。

**缩略图与摘要图**
- 缩略图：
  - 透明底，长边 512 像素，WebP；
  - 宽高比限制在 1:2 到 2:1。
- 摘要图：
  - 正、侧、背、顶四个正交视图拼成 2×2，每格 512 像素，共用一个比例；
  - 不透明底。
- 缩略图与对比视图的色调映射固定为 ACES，曝光为 1。

**色调映射**
- 可选 ACES（默认）、AgX、中性、无。
- 曝光 −3 到 +3 EV。

**环境**
- 内置的环境在代码里生成：工作室、日落、阴天、夜晚。不带 HDRI 文件。
- 背景另有「透明」选项。

**网格悬停转台**
- 悬停 500 毫秒后开始。
- 模型绕自身包围盒中心的竖直轴转，相机、灯光、环境都固定。
- 机位按缩略图的角度取一次。缩放与居中按转一整圈（24 个角度）的投影并集来定，任何角度都不出框，转的过程中不忽大忽小。
- 只在已经有缩略图时才转。触屏上不转（ADR-032）。
- 最近准备好的 3 个模型留在内存里，按 GUID 与内容指纹区分。

**贴图密度视图**
- 每个网格的每米纹素数，与整个模型的中位数比：
  - 高于 1.5 倍显示红色；
  - 低于 0.67 倍显示蓝色；
  - 其余显示绿色。
- 没有 UV 或贴图时，提示「这个格式不支持」。

**工具条布局固定（E-26）**
- 分屏时，通道按钮保留位置但隐藏，工具条不跳动。
- 各路的通道在视口上的标签里选。

**另存为图片资产**
- 输出正方形 PNG，边长 256、512 或 1024 像素，默认透明。
- 复制模型的标签与没断的归属关系，加一条指向模型的来源关系。
- 生产记录的方式为 `render`，参数记通道、相机、环境、尺寸与是否透明。

**对比控件**
- 对齐与透明度控件放在插件自己的对比视图里。
- 模型对照四视图：
  - 有「按高度」「按宽度」两种对齐，有「模型的不透明度」滑块；
  - 四视图的比例由正视图格子里图形的宽度对上目标宽度来定；
  - 不做像素差异。

**压缩扩展**
- 只接了 Meshopt，Draco 与 KTX2 不解码：
  - 遇到 Draco 或必需的 KTX2，查看器显示「这个模型无法解码」，带重试与「下载原文件」；
  - 可选的 KTX2 贴图退回普通图片；
  - 服务端照样读出面数等信息。

## 替代方案与否决理由

- **转台时相机与灯光绕模型转**：高光跟着走，看起来像相机在动，看不出模型在转。
- **每帧按当前角度重新取景**：模型转到细长的一面时会忽大忽小。
- **FBX 的 Phong 材质直接显示为读不出**：大量旧模型会整片显示不了，转成标准材质至少能看形状与颜色。
- **带上 Draco 与 KTX2 解码器**：解码器要从外部加载或打进插件，体积大；第一期样例与目标格式不需要。

## 兼容影响

- knowledge/features/builtin-plugins.md：3D 模型一节、模型对照四视图。
- 模型插件的渲染错误还没有标 `retryable`（见 ADR-055）。
- 模型对照四视图只看左上角的颜色判断背景，图片查看器看四个角里的多数。同一张四视图，两处算出的图形范围可能不同。
