# ADR-064：新手引导分散到各处讲，用小手指指着具体的按钮；新类型文件能做什么由格式插件说

状态：Accepted
日期：2026-11-26

## 背景

- 欢迎页（ADR-063）之后，第一次用的人面对三栏、十来个页面（详情的查看 / 关系 / 版本 / 校验、对比、校验队列、完整性、回收站、标签、设置）和一堆按钮，没有任何地方说这些是做什么的。
- 资产库里会陆续出现不同类型的文件，每类在查看器里能做的事不同（模型能看通道、分屏、和四视图对照），不打开就不知道。
- 内核不认识格式（ADR-003），不能替插件说某类文件能做什么。
- 使用者定下：一次只谈一条，界面文字要少；引导要指着那一页最主要的功能按钮，旁边一个小手指指着它（2026-11-26）。

## 决策

**分散到各处讲**
- 浏览页上一个五步导览，只讲这一页看得见的：左栏「待审」、网格第一个资产、搜索框、检查器的标签分区、左下角设置。
- 其他页面（详情的四个页签、对比、校验队列、完整性、回收站、标签、设置）各在第一次打开时出一条提示，指着这页最主要的那个按钮。

**一个样子：气泡 + 小手指**
- 一个小标题、一句话、按钮；气泡与被指的按钮之间一个手指图标，指尖朝着按钮轻轻点动（代替气泡的尖角），按钮外一圈淡淡的强调色描边。减少动态效果时手指不动。
- 不挡操作、不抢焦点；屏幕上始终只有一个；要指的东西不在屏幕上就等它出现。

**什么时候出现**
- 导览：网格里第一次有资产、首次登记做完之后。空资产库不出。
- 各页提示：第一次打开那一页时；「知道了」或直接点被指的按钮都算看过。
- 新文件提示：网格里第一次看得到某一类文件时，指着那个文件；一类按格式插件声明的格式算。一条关掉后，下一条等使用者换了地方再出。
- 先后：导览 → 当前页面的提示 → 新文件提示。

**跳过、关掉、再看**
- 导览上的「跳过」只结束导览，各页提示照常出现。
- 左栏左下角加一个「?」，菜单里「重新看导览」与「关掉提示 / 打开提示」。
- 看过什么、开没开，记在这个浏览器里，不分资产库。

**新类型文件的那句话由格式插件给**
- `FormatView` 加可选的 `intro(locale)`，返回一句话；不给就不出这一类的提示。
- 内置的图片、视频、音频、3D 模型、文档五类都给。

## 替代方案与否决理由

- **一次带着走完**（一个长导览自动跳到详情页、对比页、校验队列……）：步数多；空资产库时没有东西可指；跳页面时依赖具体的资产，容易断。
- **只给一张功能一览**：一张清单看不出东西在界面上的哪里。
- **页面顶上一条横幅**：使用者否掉——泛泛地说一句，不如指着那个按钮。
- **右下角提示条**：几秒后消失，容易漏看，也和操作结果的提示条挤在一起。
- **呼吸的小圆点、只有描边**：不如手指直白。
- **跳过就是全关**：只是不想看这一套导览的人，也看不到后面各页的提示了。
- **设置 › 本机里放「重新看一遍」**：不好找；使用者选了左下角的「?」。
- **新文件提示用提示条，或等第一次打开时指着查看器里的按钮**：提示条容易错过；指查看器里的按钮要插件告诉外壳指哪个元素，而且不打开就不知道。
- **新文件提示一条接一条**：第一次打开一个文件很多的资产库时，导览之后会连着十来条。
- **记在服务端或资产库里**：没有账号（内核不做登录），一个资产库常有几个人用，各人看没看过不该互相影响。

## 影响

- 新增 knowledge/features/onboarding.md；web-shell.md 左栏页面入口（四个按钮）；plugin-system.md、docs/plugin-development.md 的 `FormatView.intro`；builtin-plugins.md 各插件的那句话。
- design/docs/copy.md「新手引导」、pages.md「新手引导」。
- `@bowerbird/plugin-sdk` 的 `FormatView` 加一个可选钩子，旧插件不受影响。
- 浏览器测试默认关掉提示，只有新手引导的测试打开。
