# ADR-026：一个资产库是一个根文件夹，可以有多个并切换；接口地址带上是哪个库

状态：Accepted
日期：2026-11-25

## 背景

总览文档写的是「一个进程服务一个资产库，需要多个资产库时启动多个进程」。原型的资产库菜单里却有「切换资产库…」，审查报告建议去掉它。

讨论的结论是保留：以后一定会有多个项目，例如项目 A、项目 B 各有一个资产库，要能切换。一个资产库本质上就是一个根文件夹。

## 决策

- **一个资产库是一个根文件夹**。一个 Bowerbird 可以登记多个资产库，在界面上切换。
- **切换是每个浏览器自己的选择**，不是整台服务器一起切。一个人切换，不影响其他人正在看的页面。
- **接口地址带上是哪个库**。与资产库内容有关的接口都以库的标识区分。
- **第一期可以只打开一个库**，但接口的形状现在就按多库定下，以后加切换时不用返工。
- 索引本来就按库分开存放在本机数据目录，这一点不变。

## 替代方案与否决理由

- **一个进程只服务一个资产库**（原定做法）：实现最简单，但多个项目要开多个进程、记多个端口；以后改成多库时所有接口地址都要变。
- **整台服务器切换当前资产库**：接口不用带库标识，但一个人切换会让所有人的页面跟着变。

## 兼容影响

- knowledge/features/overview.md 进程与部署形态。
- knowledge/features/api-and-agent.md 通用约定：接口地址里的库标识。
- knowledge/features/web-shell.md 资产库菜单、路由。
- knowledge/features/library-format.md 本机配置里的已知资产库。
- knowledge/features/engineering.md 启动参数。
- 原型：保留「切换资产库…」，把「在访达中显示」改为「在文件夹中显示」。
