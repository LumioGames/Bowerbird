# ADR-036：切图与效果图对比时，按生产记录里的区域自动裁剪

状态：提议
日期：2026-11-25

## 背景

原型修订说明「待确认」第 5 项（E-13 后半）：切图对照效果图时，应只看效果图上被切下的那一块。区域只能来自切图那次生产记录的参数（审查结论 5.2：切图工具或 Agent 自动写进参数）。

本条是第一期实现时按「先找最接近的已有决定，找不到就选更少人工步骤、更不容易丢数据的做法」（ADR-013）补的，待评审。

## 决策

- 生产记录 `params` 里有区域时（约定键 `rect`，效果图像素坐标：一条记录只有一个产出时写 `[x, y, w, h]`；一条记录切出多张图时写成 `{ "<产出 GUID>": [x, y, w, h], … }`），对比页把效果图一侧裁到这个区域，可以并排、卷帘、叠加、差异。
- 没有区域参数时，只能并排，点其他方式时用提示条说明原因。

## 替代方案与否决理由

- **自动在效果图上找切图的位置**：属于按长相识别，结果不可靠（与 ADR-019 的理由相同）。
