空状态占据本该有内容的地方，说明这里为什么是空的，并给出下一步。

**你提供**：一个图标、一句标题、一句说明、一到两个动作。

- 标题说现状或邀请，不说「暂无数据」。说明里写出是哪个资产库、哪组条件。
- 第一个动作是最可能的下一步，用主要按钮；全新的资产库只有一个主要动作：把文件放进来。
- 搜索无结果时把当前条件原样显示出来，并提供「去掉某一条」的捷径，比「清空」更有用。
- 「没有问题」「队列审完了」也是空状态：用对勾图标，标题写结果（「42 个都审完了」），不必给动作。
- 背景是一层 16px 间距的点阵，向边缘渐隐；它只出现在空状态和关系图的画布上，不要用到别处。
- 加载中不是空状态：用占位的网格单元（`waiting` 的样子），不要先闪一下空状态。
