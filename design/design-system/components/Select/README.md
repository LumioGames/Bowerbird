下拉菜单从一组固定的值里选一个，收起时显示当前值。

**你提供**：触发器 `bb-select`（前面可带一个 `bb-select__label` 说明这是什么）、选项列表（一个 `bb-menu`，`role="listbox"`），以及当前值。

- 列表从触发器的左下角长出来（`transform-origin` 设在触发器上），沿原路收回。
- 当前值前面有对勾；有对应快捷键的选项在右侧显示键帽（阶段的 1、2、3）。
- 选项是物料阶段时，直接用 `Bowerbird.html.stage()` 的色标加文字，不要只写字。
- 选项不超过四个、且是视图切换时，改用分段控件。
- Esc、点空白处、选中一项都会关闭；列表打开时方向键移动、回车确认。
