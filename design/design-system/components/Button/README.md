按钮触发一个立即发生的动作；一屏里最多一个主要按钮。

**你提供**：文字（动词开头，说清楚会发生什么）、可选的前置图标、可选的快捷键帽。

| 类 | 用在 |
|---|---|
| `bb-btn bb-btn--primary` | 这一屏的主要动作：上传、通过、确认。每个视图最多一个。 |
| `bb-btn` | 次要动作。 |
| `bb-btn bb-btn--ghost` | 顶栏里的图标按钮、对话框的取消。 |
| `bb-btn bb-btn--danger` | 只用于确认框里的破坏性确认。入口处的「删除」用普通按钮或菜单项。 |
| `bb-btn--sm` / `bb-btn--lg` | 22px：提示条与检查器里的行内动作。36px：对话框与校验队列。 |
| `bb-btn--icon` | 只有图标的方形按钮，必须带 `aria-label`。 |

- 开关型按钮用 `aria-pressed`，不要换颜色。
- 按下反馈在 pointer-down 时出现（缩到 0.97、填充立刻变深），动作在松手时提交。
- 不可用时用 `disabled`，并在旁边或悬停提示里说明原因；不要把不可用的主要动作直接藏起来。
- 文案写结果，不写「确定」：用「移入回收站」「把引用改指到副本」。
