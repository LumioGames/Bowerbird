# ADR-048：位置名只能是资产库内的相对路径，导出时不得写出目标目录

状态：提议
日期：2026-11-25

## 背景

位置名（`slot`）来自资产文件里写的引用名，导出与取用时按它写出依赖文件（ADR-018）。审查发现位置名没有任何约束：别人共享的资产库里可以写 `../../.zshrc` 这样的位置名，带依赖导出时就会把文件写到导出目录之外（ADR-012：打开别人的资产库不得执行或写出任何东西）。

本条是第一期实现时（内核审查之后）按 ADR-013 补的，待评审。

## 决策

- 位置名必须是相对路径：不能以 `/` 或盘符开头，不能含 `..` 段，分隔符统一为 `/`。
- 登记、新增或更换关系时位置名不合法：返回 `validation_failed`。
- 扫描读到不合法的位置名：关系保留，但这一条不参与按位置名取文件与导出，登记一条「元数据冲突」问题说明原因。
- 导出（复制到目录或打包下载）写出的每个路径都要在解析后落在导出目录内，否则跳过并在结果里说明。

## 替代方案与否决理由

- **导出时把 `..` 静默去掉**：改变了文件里写的引用名，导出后模型仍找不到贴图。
