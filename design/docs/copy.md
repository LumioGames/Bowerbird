# 文案清单

原则：每条都要让不了解内部机制的美术同学看懂「发生了什么、接下来会怎样」；说结果，不说存储机制（E-14）。按钮顺序统一为「取消」在左、主要操作在右；会删东西或扩大访问范围的主要按钮用危险色。确认类对话框居中；通用提示条从右下角弹出、叠放、悬停不消失，带撤销的停留更久（ADR-021）。
