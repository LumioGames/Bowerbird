# ADR-038：两人同时修改：标签按增删提交；校验队列提交前核对内容

状态：提议
日期：2026-11-25

## 背景

原型修订说明「待确认」第 7 项（E-23）：两个人同时改同一个资产的标签时，后写的会覆盖先写的；两个人同时审同一个资产时会重复审。

本条是第一期实现时按「先找最接近的已有决定，找不到就选更少人工步骤、更不容易丢数据的做法」（ADR-013）补的，待评审。

## 决策

- 修改标签的请求带「增加哪些、去掉哪些」，内核在当前值上应用，不整体替换。
- 校验队列提交结论时带上看到的内容指纹；已经被别人审过（结论或内容变了）就返回冲突，界面跳过这一个并用提示条说明。

## 替代方案与否决理由

- **加锁**：多数时候没人冲突，锁只会添麻烦。

## 兼容影响

- knowledge/features/api-and-agent.md `PATCH /assets/{id}` 与 `POST /assets/{id}/review`；web-shell.md 校验队列。
