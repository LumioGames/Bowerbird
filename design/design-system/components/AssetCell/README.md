网格单元是一个资产在网格里的样子：缩略图、名称，以及四个角上的标记。

**你提供**：一个资产对象（`name`、`path`、`kind`、`stage`、`review`、可选的 `issue`、`info`、`state`、`alpha`）。`Bowerbird.html.cell(asset, { selected, arrive })` 生成标记；放进 `bb-grid`，列宽由 `--bb-cell` 控制。

**缩略图的状态**（`data-state`）

| 状态 | 缩略图里显示 | 角标 |
|---|---|---|
| `ready` | 缩略图。带透明通道的图片衬棋盘格（`bb-cell__thumb--alpha`）。 | 四个角照常 |
| `processing` | 格式图标、正在做哪一步、进度条；边缘有一道光在走。 | 阶段、校验 |
| `waiting` | 虚线圆与「缩略图稍后生成」。模型和视频的缩略图由打开着的页面在后台渲染。 | 阶段、校验 |
| `failed` | 格式图标与朱红的「处理失败」。 | 阶段，加警告级问题旗标 |
| `unknown` | 通用文件图标与后缀名。没有插件认领，仍可打标签、建关系。 | 阶段、校验 |
| `missing` | 最后一次的缩略图去色、压到三成；名称加删除线。 | 阶段，加错误级问题旗标 |

- 文档类资产没有缩略图：单元里直接排标题和开头几行，底部渐隐。
- 选中：单元铺 `accent-soft`，缩略图描 `accent-ring`，名称衬 `accent-fill`。三处一起变，在任何作品上都认得出。
- 悬停只加一层 `fill-rest`；按下缩到 0.985。悬停时的预览（视频拖动、音频试听、模型旋转）由格式插件接管缩略图区域。
- 缩略图到达时淡入、去模糊、上移 6px 一起发生（`duration-arrive`），一批到达时每个错开 45ms。不要让图片直接跳出来。
- 名称单行截断，完整路径放在 `title` 里；标签、大小、时间不上单元，去列表布局和检查器里看。
- 缩略图的容器是 `surface-well`，网格的底是 `surface-canvas`：两层都是中性灰，作品的颜色只和灰比。
